# 사례 5. 공개 PPE 데이터로 잰 성능이 XIAO 카메라에서 재현되지 않은 사례

- 관련 결정: [ADR-12](../DECISIONS.md#adr-12), [PPE 실기 검수](../PPE_ACCEPTANCE.md)
- 측정 기록: [3.7.2 공개 데이터 평가](../../field_tests/results/20260918_3.7.2-ppe-model/report.md), [웹캠 30cm·100cm 시험](../../field_tests/results/20260919_ppe-pc-test/summary.md), [2026-10-06 XIAO 실측](../../field_tests/results/20261006_ppe-xiao/summary.md)
- 데이터: [PPE 데이터 카드](../ppe-data-card.md)

## 초기 가설

공개 PPE 데이터셋(Roboflow 공개 세트 4개 병합, 검증 321장, [PPE_TRAIN.md 1.1~1.2](../internal/PPE_TRAIN.md))에서 성능이 나오면 로봇 카메라에서도 비슷하게 나온다고 봤습니다. 첫 모델(YOLOX-Nano)은 이 검증셋에서 mAP@0.5 78.7%, 위반 검출률 0.822, 오알람 0.090 을 냈습니다([3.7.2 보고서](../../field_tests/results/20260918_3.7.2-ppe-model/report.md)). 보고서는 «XIAO 프레임 평가 미실시» 를 미완료 항목으로 이미 적어 두었지만, 그 차이가 얼마나 클지는 재지 않은 상태였습니다.

## 관측된 실패

| 날짜 | 모델 | 조건 | 결과 |
| :--- | :--- | :--- | :--- |
| 2026-09-22 | 3.7.2 와 같은 모델(SHA-256 `ee46da01…`) | XIAO 부분 실측 | 11구간 중 4구간만 관측, 판정 가능률 14%, 실효 성공률 7% |
| 2026-09-28 | 후보 v23b(YOLOX-S 5클래스) | XIAO, 직립·전부 착용 69.4초 | 적합 668 · 위반 227(19%) · 확인불가 299, 정상 착용자에게 위반 확정 4회(4방향 각 1회) → 기각 |

v23b 의 오검출은 두 유형이었습니다. 정면에서 주황 안전모를 `no_helmet` 으로, 측면에서 조끼를 `no_vest` 로 읽었습니다([PPE_ACCEPTANCE.md «현재 상태와 다음 작업»](../PPE_ACCEPTANCE.md)). 두 실측의 결과 폴더(`20260922_ppe-xiao-run2`, `20260928_ppe-xiao`)는 커밋되지 않아 수치는 검수 문서의 기록으로만 인용합니다.

## 근거 데이터

- **공개 데이터 점수와 XIAO 결과가 따로 움직였습니다.** v23b 는 Mendeley test AP50 96.0 으로 높았지만 XIAO 에서는 정상 착용자 오경고로 기각됐습니다. 같은 잣대 비교표에서 Roboflow test AP50 은 v1 87.4 · v2 85.8 · v23b 68.2 였고, 운용 경로 목업(정답 사진에 운용 판정 함수를 그대로 돌림, Roboflow test 173명)에서 정상 착용자를 위반으로 읽은 수는 v2 2 · v1 4 · v23b 7 이었습니다. 같은 수치를 설정 주석은 «2/108 (v23b 7/108)» 로 적어 분모가 다릅니다([PPE_ACCEPTANCE.md](../PPE_ACCEPTANCE.md)). 목업은 정지 사진이라 XIAO 를 대신하지 못하며, 검수 문서도 «채택은 XIAO 로만 판단한다» 고 적었습니다.
- **카메라 높이가 낮을수록 판정이 줄었습니다.** 웹캠 시험에서 확인불가는 100cm 에서 구간당 3~7건, 30cm 에서 21~25건이었고, 기록은 «로봇 카메라는 15cm 라 실제 운용은 이번 30cm 보다 불리하다» 고 결론 냈습니다([웹캠 시험](../../field_tests/results/20260919_ppe-pc-test/summary.md)).
- **3.7.2 보고서의 평가 범위 자체가 좁았습니다.** 검증셋에 배경 프레임이 없어 배경 오탐률을 재지 못했고, XIAO 프레임 평가도 하지 않았습니다([3.7.2 보고서](../../field_tests/results/20260918_3.7.2-ppe-model/report.md)).

## 원인

공개 사진은 사람 눈높이나 CCTV 높이에서 찍힌 것이 대부분이고, 로봇 카메라는 바닥에서 15cm 높이에서 올려다봅니다. 학습 문서는 no_helmet 박스 2,597개 중 85% 가 «둘 다 미착용» 묶음에서 나왔고, 그 묶음의 절반 이상이 먼 CCTV 사진이라 머리 박스 면적 중앙값이 화면의 0.42% 였다고 기록합니다([PPE_TRAIN.md 3.7](../internal/PPE_TRAIN.md)). 시점·화각·조명이 다른 분포에서 잰 점수는 로봇 카메라의 점수가 아니었습니다. 이 해석은 위 측정과 학습 문서의 진단을 합친 것이며, 시점만 바꾼 통제 실험으로 분리해 확인하지는 않았습니다.

## 변경

1. **채택 기준을 XIAO 실측으로 옮겼습니다.** 공개 데이터 점수는 후보를 고르는 데만 쓰고, 채택은 mechdog-01 의 XIAO 실측과 측정 전에 고정한 합격 기준 C1~C3 로 판단합니다([PPE_ACCEPTANCE.md «합격 기준 C1~C3»](../PPE_ACCEPTANCE.md)).
2. **로봇 시점 데이터를 학습에 넣었습니다.** ppe-v5 는 v4 에 팀원 한 명의 하단 각도 촬영 279프레임(400프레임 중 121 제외)을 더해 미세조정한 모델입니다([models/NOTICE](../../models/NOTICE), PR #385).
3. **XIAO 수집 규칙을 정했습니다.** 학습·검증용 세션(a)과, (a)와 다른 날 또는 다른 장소(가능하면 다른 인물)에서 찍는 독립 시험 세션(b)을 나눕니다. 2026-09-28 세션은 (a) 로만 씁니다([PPE_ACCEPTANCE.md «XIAO 수집 세션»](../PPE_ACCEPTANCE.md)).

## 동일 조건 재평가

PR #385 는 v4 와 v5 를 같은 평가 세트로 비교했습니다.

| 지표 | v4 | v5 |
| :--- | ---: | ---: |
| 기존 공개 test AP50 | 0.853 | 0.818 |
| 하단 각도 검증 AP50 | 0.969 | 1.0 |
| 하단 각도 착용자 58명 → 적합 | 43 | 58 |
| → 오경보 | 2 | 0 |
| → 판정 불가 | 13 | 0 |

공개 test 점수는 오히려 내려갔고, 로봇 시점 점수는 올랐습니다. 공개 점수로만 골랐다면 v4 를 남겼을 것입니다.

그다음 v5 를 XIAO 로 실측했습니다(2026-10-06, 운용 창 `1500ms / 3회`). 직립 4구간에서 C1(적합 구간 위반 확정 0회), C2(구간별 4방향, 그중 3방향은 이월), C3(판정 가능률 4880/5913 = 82.5%)를 모두 통과했습니다([2026-10-06 XIAO 실측](../../field_tests/results/20261006_ppe-xiao/summary.md)). 2026-09-22 의 판정 가능률 14% 와 견주면 크게 올랐지만, 모델·구간·창 설정이 모두 달라 같은 조건 비교는 아닙니다.

## 남은 한계

- v4 는 XIAO 로 실측한 적이 없습니다. 그래서 «하단 각도 보강이 XIAO 성능을 올렸다» 는 XIAO 기준의 같은 조건 비교로는 확인되지 않았습니다. PR #385 의 하단 각도 평가도 한 사람·한 장소에서 찍은 것입니다.
- `standing-nohelmet` 후면 314건 중 235건을 적합으로 오판했습니다. 뒤에서 본 맨머리는 여전히 약점이며 C1~C3 에는 잡히지 않습니다.
- 이월을 빼고 새 확정 에지만 세면 C2 는 2·2·1방향으로 하한 3방향에 못 미칩니다.
- 합격 범위는 측정 뒤 사용자 결정으로 직립 4구간으로 줄였습니다. 웅크림·머리 잘림·자세 상승 구간은 XIAO 로 검증하지 않았습니다.
- 독립 시험 세션(b)은 아직 찍지 않았습니다. 수집 기록 표가 비어 있습니다.
