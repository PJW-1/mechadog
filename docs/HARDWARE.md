## 1. 착수 게이트 — 셋만 통과하면 된다

| # | 확인 | 통과 못 하면 |
| :-: | :--- | :--- |
| **G1** | **순정 펌웨어를 백업하고 복원까지 성공** (OI-20) | ⚠️ **커스텀 펌웨어 업로드 금지.** 되돌릴 수단이 없다 |
| **G2** | 메인 ESP32 가 Wi-Fi STA 로 공유기에 접속 (OI-1 / RISK-01) | 명령 경로를 **XIAO UART 중계**로 바꾼다 (+2.0 M/D, 가정 A-1) |
| **G3** | Phase 2 최종 구성을 **마스트 높이에** 얹고 Trot 3m · 최대 조향각 선회 1바퀴 · 10분 연속 (OI-2 / RISK-02) | Phase 2 를 **ArUco 마커 구역 정의**로 대체 |

**G1 → G2 순서를 지킨다.** 백업 전에 업로드하면 순정으로 돌아갈 수 없다.

> **G2 를 펌웨어 작업의 첫 항목으로 둔다.** 30분이면 되고, 실패하면 구조가 통째로 바뀐다.
> 실패 시 대비로 **여유 UART 핀이 노출되어 있는지**(OI-3)도 같이 본다.
>
> **G3 은 무게가 아니라 무게중심이 문제다.** LiDAR 는 마스트 위에 올라간다 — 바닥에 얹어
> 시험하면 통과해도 실제로는 넘어진다.

### 지나가면서 같이 확인할 것

| 항목 | 왜 | 반영처 |
| :--- | :--- | :--- |
| **최소 회전 반경** (OI-22) | 제자리 회전이 불가하므로(DR-11) 경로가 호로만 그려진다. 이 값에서 **필요 시연 공간 규격**이 나온다 | 장소 선정 (OI-19 와 연동) |
| Pitch Up · 앉기 자세의 IMU 몸통 피치 | 전도 임계(임시 60°)에 닿으면 안 된다. **닿으면 억제 플래그가 아니라 자세를 완만하게** (DR-16) | `config.safety.tip_angle_deg` |
| 서보 오프셋 · 조향 보정 (3대 각각) | 개체차. 기준기 값을 다른 기체에 복사하지 않는다 | `config/devices/*.yaml` |
| 로봇→WSL2 UDP 도달 · 개체별 IP·포트 | `.wslconfig` mirrored 필요. 넓은 공간은 2.4GHz 커버리지가 문제된다 | RISK-05 · RISK-09 |
| 본체 연속 보행 시간 (OI-4) | **병목은 보조배터리가 아니라 본체 배터리다** (추정 30~60분). 시연 세션 길이가 여기서 나온다 | 시연 구성 |

## 2. LiDAR 노드 배선 `[P2]`

**보조배터리 → ESP32-DevKitC → LD19.** LiDAR 전원을 DevKit 의 `5V` 핀에서 뽑으므로
**GND 가 자동으로 공통**이 된다(UART 성립 조건). 하네스 4선을 핀에 하나씩 꽂으면 끝이고,
**납땜과 브레드보드는 쓰지 않는다.**

| LD19 핀 | ESP32 핀 | 비고 |
| :--- | :--- | :--- |
| Pin4 `P5V` | `5V` | 왼쪽 맨 아래 (`5VD`) |
| Pin3 `GND` | `GND` | GND 3개 중 아무거나 |
| Pin1 `Tx` | **`GPIO16`** (UART2 RX) | 오른쪽 |
| Pin2 `PWM` | 미연결 | 데이터시트: 미연결·Hi-Z 시 내부 제어 10Hz |

**실제로 연결하는 것은 3선이다.**

### 쓰면 안 되는 핀

| 핀 | 이유 |
| :--- | :--- |
| **GPIO6~11** | **플래시 메모리 연결. 사용 금지** |
| GPIO1 / GPIO3 | USB 시리얼 — 물리면 **펌웨어 업로드가 막히고 로그가 깨진다** |
| GPIO0 / GPIO2 / GPIO12 / GPIO15 | 스트래핑 핀 — 부팅 모드에 영향 |

GPIO16 대신 GPIO25 · 26 · 27 · 32 · 33 도 쓸 수 있다.

> ⚠️ **WROVER 는 GPIO16·17 을 PSRAM 이 점유한다.** 상품명에 `WROOM` 을 확인하고,
> WROVER 라면 RX 를 GPIO25 등으로 옮긴다.

### 연결 전에 반드시

| | |
| :--- | :--- |
| **기판 실크를 직접 대조한다** | 하네스 **선 색으로 핀을 판단하지 않는다.** 색은 제조사가 임의로 정한다. LD19 기판의 `TX/PWM/GND/P5V` 표기를 본다 |
| **멀티미터로 전원선을 확인한다** | 물리 핀 순서가 1차 출처로 확정되지 않았다. **역결선하면 LiDAR 가 파손된다** |
| **연결 후 `5V` 핀 전압을 잰다** | **4.5V 이상**이면 통합 유지, **미만이면 LiDAR 를 배터리에서 직접 급전**으로 분리한다 (LD19 허용 하한 4.5V) |

> **전압 강하는 딱 끊어지지 않고 서서히 나타난다.** DevKit USB 커넥터 하나에 DevKit(200mA) +
> LD19(200mA) ≈ 400mA 가 몰리는데, 500mA 폴리퓨즈 제품이면 마진이 얇다. 증상은
> *"가끔 리셋되고 이유 없이 불안정하다"* — **가장 찾기 어려운 형태의 고장이다.** 조립 직후에 잰다.

> **2대를 동시에 돌려본다.** LiDAR 는 3대 중 2대에 장착한다. 상호 간섭 여부가 OI-21(협동
> 시나리오)의 입력이다. 자기 차폐(스캔면이 몸통 최고점보다 낮으면 전방이 막힌다)도 함께 본다.

## 3. 발주

### 필수

| 항목 | 수량 | 확인할 것 |
| :--- | ---: | :--- |
| **LD19 D500 키트** | 2 | LiDAR 노드 2대분. USB 어댑터 · 리본 케이블 동봉 확인 |
| **ZH1.5 → 듀폰 낱개 암 ×4, 20cm** | 2 | ⚠️ **스펙에 `ZH` 또는 `1.5mm` 표기가 있는지.** 사진으로는 GH(1.25)·PH(2.0)·XH(2.54)와 구분 불가 |
| | | ⚠️ **끝단이 낱개 암 4개인지.** 4핀 일체형 하우징은 목적지 핀이 흩어져 있어 쓸 수 없다 |
| | | ⚠️ **길이 20cm 이상.** 마스트↔몸통 거리. 10cm 는 부족할 수 있다 |
| **ESP32-DevKitC V4** | 2 | WROOM-32E · 38핀 · USB-C · **핀헤더 기장착**(무납땜의 전제) |
| **보조배터리 5,000mAh · 2구** | 3 | 3인 동일 사양. 보유분이 있으면 그만큼 제외. **다중 포트 동시 출력 확인**(USB-C 입출력 겸용 제품 주의) |
| **멀티미터** | 2 | **LiDAR 노드 담당 2인이 각자 집에서 조립한다.** 한 팀으로 움직인다는 것은 역할 분담이지 같은 장소가 아니다 (WBS 8절) |
| **안전모 · 안전조끼** | 각 1 | FR-9 시연. 1세트로 착용/미착용 4가지 조합이 나온다 |
| 마운트 자재 (알루미늄 앵글 · 나사) | — | 마스트. DevKit STEP 파일이 제공되므로 홀더 설계에 쓴다 |

### 예비 — 노드가 2대이므로 2대분

발주 기회가 1회다. **없을 때 막히는 비용이 부품값보다 크다.**

| 항목 | 수량 | 언제 |
| :--- | ---: | :--- |
| 25핀 미니 브레드보드 | 2 | 케이블 규격이 안 맞거나 끝단이 낱개 암이 아닐 때 (뒷면 접착층 유무 확인) |
| 듀폰 점퍼 3종 세트 (암암·암수·수수) | 2 | 위 + 상비품 |
| USB 전원 케이블 (한쪽 낱개선) | 2 | **LiDAR 전원 분리 시** — 브레드보드 전원 열에 꽂으면 납땜 0 을 유지한다 |
| USB 분배 케이블 (1→2) | 2 | 같음 |

### 사지 않는 것

**A4 프린터 출력으로 끝나는 것** — ArUco 마커(구역 2~3장 + 사원증 1장). 사원증만 코팅하면 충분하다.
**USB-C 케이블** — XIAO · DevKit 둘 다 USB-C 라 폰 케이블로 해결된다.

**부품 제외 근거**(MT3608 · TP4056 · LiPo · 벌크 커패시터 · MPU6050)는
[아키텍처 1.3](ARCHITECTURE.md)에 있다.

> **검토** — 로봇 본체 2S 여분 배터리. **시연 당일 방전이 유일하게 남는 전원 리스크다.**

> ⚠️ **G3 에서 무게 초과가 나와 LiPo 구성으로 되돌릴 경우**, 납땜 12~15점이 발생하고
> **순서를 지키지 않으면 LiDAR 가 파손된다** — ① MT3608 에 배터리만 물린다(LiDAR 미연결)
> → ② 멀티미터로 출력을 5V 로 맞춘다 → ③ 전원을 끊는다 → ④ 그 다음 LiDAR 를 연결한다.
> MT3608 은 가변저항 모듈이라 출하 상태가 5V 라는 보장이 없다. ②를 건너뛰는 것이 가장 흔한 사고다.
