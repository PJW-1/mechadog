# 작업방 전역 정합 보정 (2026-10-03)

문제: 전역 탐색이 10cm·15도 격자의 최고점 하나만 전체 스캔으로 정밀화했다.
실제 작업방 기록에서는 다른 위치가 거친 점수에서 앞서지만, 작업방 후보를
정밀화하면 전체 점수가 더 높아지는 경우가 있었다.

`global_match`는 동일한 상관 점수와 기존 정밀 탐색을 사용해 서로 다른 강한
봉우리를 최대 8개 비교한다. 정밀 후보는 관측된 빈 바닥에 있어야 하며,
반올림 전 전체 스캔 점수가 낮아지는 후보는 채택하지 않는다.
모호성은 반환하는 후보 기준으로 계산한다. 30도 경계의 부동소수점 오차도 제외한다.
지도 원본, 센서 변환·거리 단위, IMU 사용법, 모호성 허용치와 안전 정지는 바꾸지 않았다.

## PC 검증

- 전체 시험: 3,584 통과, 2 제외, 실패 0. Ruff 통과.
- 작업방 원본 4개 기록에서 31개 완성 스캔을 재생: 전체 점수 상승 9개,
  하락 0개. 작업방 구역 후보 23→26개. 실제 위치 정확도 판정은 아니다.
- 전역 모호성 거절은 전후 모두 27/31개다. 이 변경으로 자동 위치 확정이
  해결됐다고 판정하지 않는다. 신뢰할 수 있는 기준점과 짝지은 새 기록이 필요하다.
- 전역 탐색 중앙 시간 약 258→426ms. 같은 PC의 동시 부하 시험에서
  국소 정합 80회 p95 약 9.67ms, 최대 10.58ms. 실물 통신·보행 부하 시험은 아니다.
- 25/50/75mm 우도폭 변경만으로 다른 위치·방위 선택이 남아 설정 조정은 채택하지 않았다.
- 저장 집 지도 순찰 시뮬: 수정본 2사이클·8구역, 재계획/E-STOP 0.
  측위상실 전환은 수정 전 1사이클 4회, 수정 후 2사이클 8회였다.
  이 시뮬은 추종에 진실 좌표를 주입하므로 실제 측위 정확도의 증거로 사용하지 않는다.

원본·분석은 로컬 실물 측정 폴더의 `작업방_측위_보행잠금_215825/analysis/calibration-diagnosis/`에
분리 보존했다. 원본 측정 자료를 Git에 넣지 않는다. 실제 로봇 구동과 펌웨어 설치는 없다.

후속: LiDAR 중심의 바닥점에서 서로 직각인 실제 벽까지 거리 두 개와 벽 이름을
확인하고, 위치·방향을 유지한 새 보행 잠금 스캔과 대조한다. 눈대중 60cm는 정답으로 쓰지 않는다.
