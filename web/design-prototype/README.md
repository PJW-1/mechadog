# 웹 관제 대시보드 디자인 프로토타입

HTML·CSS·JavaScript로 만든 화면 검토용 웹입니다. **운영 서버 또는 실제 로봇에 연결되지 않습니다.** WBS 4.6 화면 설계 참고용이며 완료 기준을 충족한 운영 구현이 아닙니다.

## 로컬에서 보기

저장소 루트에서 실행한 뒤 http://127.0.0.1:4185/#dashboard 를 엽니다. 포트 사용 중이면 다른 포트로 변경하세요.

```sh
python -m http.server 4185 --bind 127.0.0.1 --directory web/design-prototype
```

## 포함된 화면

- 관제, 임무, 이벤트, 운행 기록, 구역·지도, 장치·센서, 안전·설정
- 공장 3D 개념도 및 노란 가상 MechDog 애니메이션, 재생·정지
- PC·모바일 레이아웃 및 예시 데이터 표시 전환

## 실제 구현과의 경계

- 모든 수치·이벤트·임무는 예시입니다. 지도는 실측 지도가 아닙니다.
- 가상 로봇은 고정 예시 경로 애니메이션이며 SLAM·경로계획·물리 시뮬레이터가 아닙니다.
- E-STOP·제어권·수동 제어는 UI 데모입니다. 실제 명령·ACK·온보드 안전 기능을 보장하지 않습니다.
- 판정 및 기록은 페이지 메모리 예시로 서버에 저장되지 않습니다.
- `host/dashboard/static/`으로 자동 복사하거나 호스트 런타임에 연결하지 않았습니다.
- 정본은 루트 docs의 PRD·WBS·PROTOCOL입니다. 이 화면으로 요구사항·담당·하드웨어 구성을 변경하지 않습니다.

## 검증과 남은 일

JS 문법·정적 빌드 및 로컬 브라우저 7메뉴 전환, 가상 로봇 정지·재생, 예시 숨김, 390px 모바일 화면을 확인했습니다. 실제 API/로봇, 브라우저별 호환성 및 장시간 성능은 미검증입니다. 기존 로컬 jsdom 시험은 의존성 부재로 재실행하지 못했습니다.

```sh
node web/design-prototype/build.cjs
```

운영 도입 전 WS/영상/명령/ACK 연동, 자동시험 환경, 지도 데이터 및 이미지 사용권을 검토해야 합니다. 이 폴더는 독립 디자인 검토 자료로 먼저 공유합니다.
