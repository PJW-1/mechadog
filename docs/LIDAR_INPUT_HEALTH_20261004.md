# LiDAR 입력 품질과 구역 A 정합 보정 (2026-10-04)

패킷 수신이 계속되어도 정상 회전 스캔이 없을 수 있다. 실제 복귀 기록에서
347.38도 반복과 거리 0이 들어왔고, 측위에 사용할 완성 스캔은 없었다.
`LidarFeed`는 기존 회전 조립 시간 한도(300ms)를 넘으면 입력 불완전 경고를
내고, 이후 경고는 5초마다 요약한다. 완성 스캔이 돌아오면 복구를 기록한다.
경고에는 부팅 ID, 마지막 완성 스캔 나이, 각도 범위, 무효 점 수가 포함된다.
기존 원본 기록, 회전 판정, 패킷별 비상정지와 측위 신뢰 기준은 유지한다.

저장된 실패 기록 재생에서는 완성 스캔 0/폐기 묶음 52, 경고 11건이었다.
사용자 재부팅 후 정상 기록에서는 완성 스캔 1,201/폐기 0, 경고 0건이었다.
이 변경은 진단 누락을 고치며, 센서 또는 중계의 이상 출력을 치료하는 패치는 아니다.

줄자 왼벽 61cm/정면 벽 121cm는 같은 위치의 LiDAR 원본과 일치했다.
두 벽면의 방향과 줄자 기준으로 별도 구역 A 지도를 만들고, 지도 생성에
사용하지 않은 이전/전진/복귀 기록의 9개 스캔을 비교했다. 모두 정합 점수가
상승했고 경쟁 후보 수는 0이었다. 기존 집 지도와 이전 시험 지도는 보존한다.
이 지도는 구역 A만 검증하는 후보이며 집 전체 자율주행용이 아니다.
실측 벽거리의 기준 시각을 구분해야 한다: 최초 111cm 기준과 이후 전진 직전
약 123cm의 기록은 같은 실제 자리라고 가정할 수 없다.

10월 1일 설치 기록의 중계 펌웨어는 `5f8f4dc`이다. 현재 실행용 브랜치의
중계 스케치는 이 설치본과 다르므로 현재 파일을 곧바로 설치해서는 안 된다.
간헐 입력 이상 원인을 구분하려면 설치본의 UART 진단 카운터 또는 원시 UART가
필요하다. 이번 변경에서 펌웨어 설치와 로봇 보행은 하지 않는다.

원본과 재현 도구/결과는 로컬 공식 측정 폴더
(10-04 구역 A 복귀 기록의 `analysis/registration-repair/`)에 보존한다.
저장된 실제 자료를 Git에 넣지 않는다.

## 추가 실물 검증 — 후보 지도 미채택

입력 진단 코드는 `c93f2ef`로 실행용 PC 브랜치에 통합했다. 전체 시험은
3,586 통과/2 제외, 실패 0이다. 사용자 USB 연결 후 COM9 시리얼 로그를
읽으며 새 지도 후보로 보행 잠금 60초를 기록했다. 해당 정상 구간에서는
CRC/기형 프레임/재동기화/버퍼 초과 카운터의 증가가 없었다. 과거 입력 이상이
발생한 시점의 UART 로그는 없으므로 근본 원인 해결로 판정할 수 없다.

추가 기록의 원본 거리(정면 약 110cm/왼쪽 약 63cm)는 앞선 줄자 기준과
달랐다. 이후 사용자가 USB 연결을 위해 다른 자리로 옮겼고 방향도 약 180도
돌렸다고 확인했다. 따라서 이전 좌표와의 차이를 동일 자리 측위 오차로
해석하지 않는다. 비교를 이전 111cm 기록과 추가 USB 기록까지
확대하니 최초 9개 외의 6개 스캔은 후보 지도에서 점수가 낮아졌다.
따라서 후보 지도는 기본 지도에 적용하지 않고 분석 자료로만 보존한다.
알고리즘의 `verified` 표시는 독립된 실물 위치 정답을 대신할 수 없다.

## 다른 위치 관측을 추가한 구역 A 지도 시험

가구 때문에 새 자리에서 벽까지 줄자로 재기 어렵다는 사용자 설명에
따라, 저장된 스캔의 긴 평면을 비교했다. 약 2m 길이의 서로 마주 보는 평면
후보 간격은 2.389m였다. 가구 면이 섞일 가능성과 도면 벽면 좌표의 불확실성은
남겨 두며, 이를 구역 A 실측 폭의 독립 정답으로 확정하지 않는다.

기존 격자 적분 방식으로 61/121cm 기준 지도에 새 위치의 완성 스캔 60개를
추가한 `office_multiview_candidate`를 별도 생성했다. 기존 지도와 기본 장치
설정은 변경하지 않는다. PC 15개 스캔 비교에서 새 위치의 정합 점수는 약
0.64에서 0.975로 올랐으나 이전 기록 일부는 낮아졌다. 구역 A 전체와 집 전체
지도 검증을 대신하지 않는다.

이 후보를 명시해 시드 없이 보행 잠금 120초 실수신 시험을 했다. 첫 위치를
3.243초에 획득했고, 1,195회 측위 시도 중 초기 획득 뒤 1,170회 갱신했다.
현재 위치에서의 재획득과 정지 추적은 개선됐으나, 같은 LiDAR 평면으로 지도를
정렬하고 비교했으므로 절대 위치 정확도의 독립 검증은 아니다. 송신은
STOP/LED/STATE/ESTOP이며 MOVE/POSE/RESET_SAFE는 없었다. 기록 손실은 0이다.

동시 UART 진단 24개에서 CRC/기형 프레임/재동기화/버퍼 초과 카운터의 증가는
0이었다. 사용자는 현재 PC USB가 LiDAR와 중계를 전원 공급하며, 이전 이상
입력 당시에는 보조배터리 USB를 썼다고 확인했다. 같은 자리와 방향을 유지한
보조배터리 전원 180초 시험에서는 3.183초에 위치를 재획득하고 1,797개 완성
스캔을 조립했다. 불완전 묶음 폐기/입력 경고/수신 순번 누락은 0이었다.
초기 획득 이후 1,767회 측위를 갱신했고 거리 0 비율은 약 0.0135%였다.
PC USB와 보조배터리 두 조건 모두 이번에는 정상이다. 전원 전환이 재부팅도
동반하므로 전원과 재부팅 효과를 분리하지 못하며, 간헐 이상이 해결됐다고
판단하지 않는다. 보조배터리 시험에는 UART 로그와 센서 전압 측정이 없었다.
