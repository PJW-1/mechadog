# MechaDog 흰색 관제 화면

2026-09-29 디자인 기준 · 2026-09-30 Git 통합. 기존 흰색 화면의 레이아웃과 모션을 정리했다.

## 화면 목적

Operate: 로봇과 영상의 실제 연결 상태를 파악하고, 사건·장치·제어 작업으로 이동한다. 예시 데이터와 실물 데이터를 구별하는 기존 문구와 동작을 유지한다. 기본 화면은 glass-preview이며 과거 검정 웹을 기본으로 재실행하지 않는다.

## 시각 규칙

- 흰색 작업면, 연한 회색 바탕, 짙은 녹색 선택/주요 버튼. 노랑은 참고·주의, 빨강은 실제 위험/정지 의미에만 사용한다.
- Noto Sans KR 기존 글꼴 유지. 페이지 제목 28px, 본문 13–14px, 보조 상태 11–12px. 주요 입력/조작은 작은 화면에서 충분한 크기로 유지한다.
- 900px 이상은 폭 176px(좁은 데스크톱 156px)의 고정 메뉴. hover/focus에 따라 본문 폭을 바꾸지 않는다. 작은 화면은 상단 메뉴와 세로 콘텐츠 흐름.
- 구역 간 24–36px, 묶음 내부 8–16px. 작업면은 1px 테두리, 반경 7–12px. 그림자는 카메라 창/팝업/대화상자의 겹침 표현에만 쓴다.
- 카메라는 드래그·크기 조절·확대·접기의 기존 동작을 유지한다. 휴대폰은 지도 아래 흐름에 놓는다. 사건 목록과 상세는 넓은 화면에서 두 열, 휴대폰은 한 열.

## 모션 규칙

- 화면 전환 240ms, 카메라 창 FLIP 280ms, 3D 시점 220–380ms. 클릭 처리는 즉시 완료하고 시각적 연결만 애니메이션으로 표현한다.
- telemetry/frame 갱신이나 같은 페이지의 목록 재작성마다 입장 효과를 재실행하지 않는다.
- 새 3D 조작은 현재 시점에서 다시 시작한다. 직접 드래그하거나 화면을 나가면 시점 전환을 해제한다. reduce-motion은 즉시 도착/공간 이동 제거, 색상 피드백 유지.
- 상시 배경 이동·그림자 맥동·포인터 추적 장식 없음. 렌더링은 기존 demand-render 흐름과 유한한 시점 전환을 사용한다. 성능 향상 수치는 계측하지 않았다.
- WebGL 크기는 변환 중의 시각적 bounding box가 아니라 canvas clientWidth/clientHeight로 계산한다.

## 범위와 검증

관제 웹의 8개 화면과 320–1440px 화면 폭을 대상으로 한다. 실제 로봇/센서 구동과 AI 모델 변경은 이 디자인 범위에 포함하지 않는다. 화면에 표시하는 로봇 슬롯은 최신 관제 코드의 MD-01·MD-02 두 대와 일치시킨다. 자동시험 및 정적 검사는 통합 브랜치에서 다시 실행한다.
