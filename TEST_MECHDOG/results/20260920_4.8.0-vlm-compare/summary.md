## ① 같은 사진 두 장을 «다르다» 고 한다

정답이 자명한 것부터 물었다 — 라벨링에 사람 주관이 들어가면 숫자를 믿을 수 없다.

| 입력 | 물음 | 기대 | 답 |
| :--- | :--- | :--- | :--- |
| 같은 파일 ×2 | *Are these two images identical?* | `yes` | **`no`** ❌ |
| 다른 파일 ×2 | *Are these two images identical?* | `no` | `no` |

**첫 줄이 결정적이다.** 같은 바이트를 두 번 넣었는데 다르다고 답했다. 둘째 줄이 맞은 것은
**모델이 두 장 입력에서 `no` 로 쏠리기 때문**이지 비교를 해낸 근거가 아니다 (④ 참조 —
한 장이면 `yes` 도 나온다).

## ②③ 완전히 다른 장면을 «변화 없음» 이라 한다

쓴 쌍은 같은 방의 다른 시점이다.

| | 파일 | 내용 |
| :--- | :--- | :--- |
| 기준 | `blackbox/1789664597680_person_found/` | 책상·선반·커튼이 보이는 방 전경, 사람이 구부린 자세 |
| 현재 | `blackbox/1789666217924_person_found/` | 로봇이 사람 바로 옆, **다리·팔이 화면을 가득 채움**, 침대·라디에이터 |

| 물음 | 답 |
| :--- | :--- |
| *Did any object appear, disappear, or fall over?* | **`no`** ❌ |
| *Describe in one sentence what changed.* | **"The person is no longer visible in the image."** ❌ |

서술 쪽이 특히 나쁘다. 사람이 **두 번째 사진의 절반을 차지하는데** 사라졌다고 말한다.
두 번째 이미지를 제대로 보고 있지 않다는 뜻이다.

## ④ 한 장이면 멀쩡하다 — 09-17 수치가 재현됐다

기준 사진 한 장만 주고 `vlm_reader.py` 의 고정 질문 셋을 그대로 물었다.

| 물음 | 답 | 판정 |
| :--- | :--- | :--- |
| 바닥에 누운 사람이 있나 | `no` | ✅ 구부린 자세이지 누운 것이 아니다 |
| 넘어진 물건이 있나 | `no` | ✅ |
| 통로가 막혔나 | **`yes`** | 어수선한 방이라 그럴듯하다 |

⚠️ **`yes` 가 나온 것이 중요하다.** 모델이 무조건 `no` 를 뱉는 것이 아니다 — **한 장이면
`yes` 도 나오고 두 장이면 `no` 로 쏠린다.** ①의 해석을 이것이 받쳐 준다.

| 수치 | 이번 (09-20) | ADR-35 (09-17) |
| :--- | ---: | ---: |
| VRAM (적재 후) | **4.12 GB** | 4.1 GB |
| VRAM (최대) | 4.28 GB | — |
| 질문당 (한 장) | **0.20~0.22초** | 0.2~0.9초 |
| 질문당 (두 장) | 0.34~0.89초 | — |
| 적재 | 10.0초 | 5.5초 |

적재만 두 배인데 **이번이 첫 로드**라 디스크 캐시 차이로 보인다. 예산에 영향은 없다 —
`factory` 프로파일은 여전히 ~7.1GB 로 10GB 안에 들어간다.

## 그래서

- **VLM 을 변화 «탐지» 로 올리는 길은 이 모델로는 막혔다.** 가장 쉬운 판별(같은 사진인가)
  조차 틀린다. FR-8.2 의 «객체 목록 단위 비교» 필수 제약을 고쳐 가며 갈아탈 근거가 없다.
- **변화 비교는 COCO 객체 목록이 계속 맡는다** (3.6.x · `change_detect.py`).
- **VLM 은 한 장 판독으로 보완한다** — 지금 `host/vision/vlm_reader.py` 가 하는 일이 맞고,
  ADR-35 결정 2·4 를 바꿀 이유가 없다.
- **FR-8.5(기준·현재 두 장을 VLM 에 넘겨 서술)는 이 모델로 실현할 수 없다.** 요구사항에는
  남아 있으나 2B 로는 안 된다. 되살리려면 더 큰 모델이 필요하고, 그것은 VRAM 예산을 다시
  여는 일이다.

⚠️ **남은 것 — 이 시험이 답하지 않은 것.** 쓴 쌍은 «같은 장소의 미세한 변화» 가 아니라
«장면이 통째로 다른» 경우다. 물건 하나를 치운 정도의 변화는 더 쉽지 않고 **더 어렵다**.
그래도 판별이 되는지 보려면 같은 자리에 삼각대를 두고 물건 하나만 옮겨 찍은 쌍이 필요하다.
지금 결과로는 그 시험까지 갈 이유가 없다 — 같은 사진 두 장도 구분하지 못하기 때문이다.
