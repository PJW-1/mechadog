1. conf 0.3 에서 위반 검출 0.884, 오알람 0.128

## 6. 호스트 파이프라인 확인

1. models/coco.onnx 와 models/ppe.onnx 적재 확인
2. 공개 데이터 6장으로 2단 검출이 끝까지 도는 것을 확인했다
3. 결과는 위반 4건, 확인불가 1건, 사람없음 1건
4. 개발 PC 에서 DirectML 이 검출을 전부 비워서 내보내는 문제를 확인했다
5. 같은 사진에서 CPU 는 person 0.5 에서 0.93 을 정상 검출했다
6. config/devices/mechdog-01.local.yaml 에 이 PC 만 CPU 를 쓰도록 기록했다

## 7. 판정

1. 정상 착용자를 위반으로 읽는 오알람 9% 와 안전모만 미착용을 놓치는 경우를 제외하면 정상 성능으로 예상된다
2. 위반을 통과로 읽는 최악의 오류는 1.4% 이며 임계값을 바꿔도 변하지 않는다
3. 이 수치는 공개 데이터 기준이며 FR-9 통과 판정이 아니다

## 8. 미완료

1. XIAO 실기 프레임 검증셋 촬영은 하지 못했다
2. 카메라 전원 유지 문제로 실기 관찰을 시작하지 못했다
3. 사람 없는 배경 프레임이 검증셋에 없어 배경 오검출률을 재지 못했다
4. 판정 보류 경로는 실기로 찍은 머리 잘린 프레임으로만 확인할 수 있다
5. 추론 속도는 기준 PC 인 RTX 3080 에서 다시 측정해야 한다
