# MechaDog 관제 웹 프로토타입

MechaDog 로봇 관제 화면의 구조와 조작 흐름을 검토하는 HTML/CSS/JavaScript 웹입니다. Three.js로 공장과 로봇의 예시 3D를 표시합니다. DB·로그인·실시간 영상·측위·로봇 제어는 연결되지 않았습니다.

## 실행

Node.js **24.19.0**과 npm에서 검증했습니다. `.nvmrc`로 같은 버전을 선택할 수 있습니다. 개발 검사 도구의 지원 범위는 Node.js `^22.22.2 || ^24.15.0 || >=26.0.0`이며 `package.json`에도 명시했습니다.

이 README가 있는 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

[로컬 관제 화면](http://127.0.0.1:4175/#dashboard)을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다. 서버가 이미 4175 포트를 사용 중이면 기존 서버를 사용하거나 종료한 뒤 실행하세요. `index.html`을 직접 여는 대신 HTTP 서버로 접속해야 합니다.

개인 호스팅 계정·설정·환경변수는 필요하지 않습니다. 최초 `npm ci`에는 npm 패키지 다운로드가 필요합니다. 개발 서버는 이 PC의 `127.0.0.1`에만 연결되며 휴대폰 접속용 네트워크 서버는 아닙니다. Google Fonts는 외부 네트워크를 사용하며 연결되지 않으면 기본 글꼴로 표시됩니다.

## 빌드와 검사

```sh
npm run build
npm test
```

빌드는 `build/`에 HTML/CSS/JS, 예시 공장 배치와 Three.js 실행 파일·라이선스를 복사합니다. `npm test`에는 빌드된 모듈 검사도 있으므로 빌드를 먼저 실행하세요. 정적 서버로 `build/`를 제공할 수 있으며 앱/DB 서버는 생성하지 않습니다. 의존성 버전은 `package-lock.json`으로 고정합니다.

## 현재 사용할 수 있는 화면

| 화면 | 구현 범위 |
| --- | --- |
| 통합 관제 | 예시 공장·3대 로봇 3D, 로봇 선택, 가상 로봇 시점, 예시 임무·사건 요약 |
| 순찰·제어 | 관측과 수동 조작, 예시 제어권·명령·순찰 상태, 계획/결과 화면 틀 |
| 사건 | 예시 사건 필터·검토·메모, 사용자가 고른 블랙박스 JSON/JPEG 읽기 |
| 기록 | 웹 조작 이력 검색·CSV, 예시 세션 기록 |
| 구역·장치 | 예시 위치·구역, 회전·확대 가능한 로봇 3D, 실제 상태 미수신 표시 |
| 설정 | 예시 표시/역할·정책 초안, 연결 만료 시연, 계정·사원증 등 미연결 폼 |

새 등록·저장·적용 폼과 본체 자세 조절 버튼은 비활성 준비 상태입니다. 기존 예시 검토/정책 초안 일부는 브라우저의 로컬 저장소를 사용합니다. 브라우저·PC 간 공유되지 않으며 서버 저장이 아닙니다. 블랙박스 파일은 브라우저에서 읽으며 서버로 업로드하지 않습니다.

## 수동 조작 시연

순찰·제어에서 대상을 선택하고 **예시 제어권 요청**을 누릅니다.

- `W` / `S`: 전진 / 후진 명령 상태
- `A` / `D`: 좌회전 / 우회전 명령 상태
- `Space`: 정지. 이동 키를 놓아도 정지합니다.
- 방향 버튼을 누르는 동안 명령을 유지하며, 버튼에 초점을 두고 `Enter`로도 조작합니다.

Space 유지 중에는 다른 방향 입력을 시작하지 않습니다. 입력칸·IME·브라우저 단축키·다른 페이지에서는 이동 단축키를 처리하지 않으며, 초점 이탈·대상 전환 후 자동 재개하지 않습니다. ‘키보드 조작’을 끌 수 있습니다. 이 동작은 **로컬 명령 상태/기록만 변경하며 실제 로봇과 3D 위치를 움직이지 않습니다.** 웹의 정지 버튼도 실제 장비를 정지시키는 안전장치가 아닙니다.

## 카메라와 로봇 모델

Hiwonder MechDog Advanced Kit의 외형을 참고한 표시용 모델이며 정밀 CAD·물리 모델이 아닙니다. 가상 영상·위치·방향은 예시 공장 모델에서 표시합니다.

[공식 APP 제어 문서](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/2.APP_Control.html#function-introduction)에서 본체 pitch/roll을 지원합니다. [공식 구성품](https://docs.hiwonder.com/projects/MechDog/en/latest/docs/1.Getting_Ready.html#packing-list)만으로 카메라 독립 구동이나 보유 장착물의 각도 범위는 확인되지 않았습니다. 본체 자세로 시야를 조절하는 세 버튼은 장착 범위와 펌웨어 연결을 확인하기 전까지 비활성입니다.

## 저장소 위치와 포함 파일

이 디자인은 기존 웹을 교체한 팀 저장소의 **`web/design-prototype/`**에 있습니다. 저장소 루트에서 `cd web/design-prototype` 후 npm 명령을 실행하세요. 이전 Python 정적 서버 방식은 새 개발 흐름에서 사용하지 않습니다. 운영 통합용 `host/dashboard/static/`으로 자동 복사하거나 Host 런타임에 연결하지 않습니다.

HTML/CSS/JS·`factory-layout.json`·`robot-view.js`·`scripts/`·`tests/`·package 파일·이 문서를 포함합니다. `.git/`, `.openai/`, `.impeccable/`, `node_modules/`, `build/`, `dist/`, 환경변수/로그·개인 작업일지·Isaac 원본은 포함하지 않습니다. 필수 외부 사진/GLB 파일은 없습니다.

## 검증 범위

2026-09-11 기준 앱의 Node/DOM 검사 **58개**와 정적 빌드가 통과했습니다. PC 및 모바일 크기의 브라우저에서 주요 화면·조작을 확인했습니다. `.github/workflows/web.yml`은 웹 변경 시 같은 설치·빌드·검사를 실행합니다. 실제 휴대폰 GPU/터치/FPS, 실시간 카메라·측위·DB/API·장비·Isaac 연결은 미검증입니다. 이 문서는 웹 프로토타입의 상태이며 팀 WBS의 운영 통합 완료 보고가 아닙니다.
