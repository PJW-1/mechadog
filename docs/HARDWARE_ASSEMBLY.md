## 0. 왜 무납땜을 목표로 하는가

팀에 인두 사용 경험이 보장되지 않고, **발주 기회가 1회**이므로 부품을 태우면 복구할 수 없다.
특히 LiDAR 는 13~16만원이며 재구매가 불가능하다.

**전원 실수 한 번의 비용이 부위별로 다르다.**

| 대상 | 죽으면 |
| :--- | :--- |
| XIAO | 약 1만원. 예비 보유 |
| **LD06 LiDAR** | **13~16만원. 재발주 불가 → Phase 2 종료** |

## 1. Phase 1 — 납땜이 필요한 곳

| 대상 | 납땜 | 비고 |
| :--- | :---: | :--- |
| MechDog 본체 | 없음 | 순정 조립 |
| 킷 확장 모듈 (WonderEcho · MP3 · 초음파 · 터치) | **없음** | JST 커넥터로 꽂는다 |
| 눈 LED | 없음 | 초음파 센서에 내장 (OI-12 닫힘) |
| **XIAO 전원** | **선택** | 아래 |

### XIAO 전원 — 두 갈래

| 방식 | 납땜 | 무게 |
| :--- | :---: | ---: |
| **USB-C 보조배터리** | **0회** | 40~120 g |
| BAT 패드에 LiPo 직결 | XIAO당 1회 | ~20 g |

**개발 중에는 PC 의 USB-C 에 꽂는 것이 가장 낫다.** 시리얼 로그를 함께 보며 디버깅할 수 있고
전원 문제 자체가 발생하지 않는다. **납땜 판단은 시연 준비 단계까지 미룰 수 있다.**

> **벌크 커패시터는 LiPo 직결일 때 필요한 부품이다.** LiPo 는 Wi-Fi 송신 피크에서 전압이 강하해
> 브라운아웃 리셋이 발생하므로 이를 흡수한다(PRD 2.4). 보조배터리는 정류된 5V 를 공급하므로
> 이 문제가 훨씬 덜하다. **없이 시작하고 리셋이 관측되면 추가한다.**

### LiPo 를 쓸 경우 — 납땜을 1회로 끝내는 방법

패드에 셀을 직접 붙이지 말고 **짧은 JST 피그테일을 붙인다.**

```
XIAO BAT 패드 ──[납땜 1회]── JST 커넥터 ⇄ 배터리
```

셀을 직접 붙이면 배터리를 교체할 때마다 다시 납땜해야 한다. 충전은 그 뒤로 USB-C 가 담당한다
(XIAO ESP32S3 는 충전 IC 내장).

> ⚠️ **JST PH 2.0 의 극성은 판매처마다 다르다.** 셀에 달려 나온 커넥터의 빨강 위치가 통일되어 있지 않다.
> **연결 전 반드시 멀티미터로 +/− 를 확인한다.** XIAO 에는 역극성 보호가 없어 즉시 파손된다.

## 2. Phase 2 — LiDAR 노드 무납땜 구성 [P2]

### 2.1 목표 구성

```
        보조배터리 (2구 이상)
              │
    ┌─────────┼──────────────────┐
    │         │                  │
  USB-C     USB-A ─ 분배 ─┬──── USB-A
    │                     │        │
  XIAO                   C3      [USB 터미널 브레이크아웃]
 (독립)                   │              │ 5V · GND
                          │              ▼
                          └──── RX ◀── LD06 Tx
```

| 연결 | 방법 | 납땜 |
| :--- | :--- | :---: |
| XIAO 전원 | USB 케이블 | 0 |
| C3 전원 | USB 케이블 | 0 |
| LD06 전원 (5V·GND) | USB 터미널 브레이크아웃 (나사식) | 0 |
| **LD06 Tx → C3 RX** | 듀폰 점퍼 또는 스크류 터미널 블록 | 0 |
| GND 공통 | **배터리 내부에서 이미 확보** | — |

**전제 조건 하나** — **C3 는 핀헤더가 납땜된 버전**을 구매한다. 이것만 충족되면 나머지는 꽂기만 한다.

### 2.2 GND 를 공유해야 하는 이유

전원은 기기 안에서 닫힌 회로이므로 남과 무관하다. 그러나 **신호선은 두 기기를 잇는 새 경로**이며
전류가 돌아올 길이 필요하다.

더 근본적으로, **`3.3V` 는 GND 를 기준으로 한 값이다.** 두 기기의 GND 기준이 다르면
LD06 이 내보낸 "3.3V" 를 C3 가 몇 V 로 읽을지 정의되지 않는다.

**같은 보조배터리에서 전원을 받으면 GND 가 배터리 내부에서 이어진다.** 따라서 별도 GND 배선이
필요 없고, **추가로 연결할 것은 Tx 한 가닥뿐이다.** 배터리를 분리하면 GND 선을 직접 이어야 하며,
그 한 선을 빠뜨리는 것이 가장 흔한 실패 원인이다.

### 2.3 케이블 끝단별 대응

LD06 케이블의 끝단 형태는 판매처마다 다르므로 **발주 전에 확정할 수 없다.**

| LD06 케이블 끝 | 방법 | 납땜 |
| :--- | :--- | :---: |
| 암 듀폰 핀 | C3 핀헤더에 바로 꽂는다 | 0 |
| 수 듀폰 핀 | 암-암 점퍼를 끼운다 | 0 |
| 벗겨진 선 | **스크류 터미널 블록**에 조이고 반대편에 점퍼 | 0 |

> **스크류 터미널 블록을 반드시 담는다.** 개당 몇백 원이며 **어떤 형태의 선이든 납땜 없이 물린다.**
> 이것이 없으면 세 번째 경우에 인두를 잡아야 한다. 1,000원짜리가 없어서 Phase 2 가 멈추는 것이
> 가장 아까운 실패다.

### 2.4 왜 XIAO 겸임이 아니라 별도 C3 인가 (OI-7)

| # | 근거 |
| :-- | :--- |
| ① | **XIAO 가 이미 바쁘다.** VGA 15fps 캡처·JPEG 인코딩·Wi-Fi 송신 중에 230400 baud 연속 스트림을 받아야 한다. 대역폭이 아니라 **타이밍**이 문제이며, UART 버퍼를 놓치면 스캔이 깨진다 |
| ② | **전원이 서로를 흔든다.** LiDAR 모터 부하가 XIAO 공급을 흔들면 영상이 끊긴다 |
| ③ | **배선이 로봇을 가로지른다.** LiDAR 는 마스트 위, XIAO 는 몸통이다 |
| ④ | **고장 격리가 사라진다.** 겸임하면 하나가 죽을 때 둘 다 죽는다 |

**비용 차이는 MCU 하나(약 5,000원)뿐이다.** 겸임해도 LiDAR 전원은 어차피 분리해야 한다.

## 3. 전원 용량 산정

기준은 **로봇 본체가 먼저 방전된다**는 것이다. 순정 2S 로 30~60분 추정(OI-4), 시연은 10분이다.

| 부하 | 평균 |
| :--- | ---: |
| XIAO (카메라 + Wi-Fi) | 200~250 mA |
| LD06 | ~200 mA |
| C3 (Wi-Fi) | ~150 mA |
| **합계** | **~600 mA** |

보조배터리 정격은 3.7V 셀 기준이며 5V 승압 손실로 **실사용은 정격의 60~70%** 다.

| 정격 | 5V 기준 실사용 | 600mA 기준 | 무게 |
| ---: | ---: | ---: | ---: |
| 2,000 mAh | ~1,300 mAh | 2시간 | 40~50 g |
| **3,000 mAh** | **~2,000 mAh** | **3시간** | **60~70 g** |
| 5,000 mAh | ~3,300 mAh | 5시간+ | 100~120 g |

> **3,000mAh 급이 적정하다.** 5,000mAh 는 불필요한 40~60g 을 더한다 — LiDAR 본체(50g) 하나를
> 더 얹는 것과 같으며, 무게 예산이 85g 인 프로젝트에서 이는 결정적이다.

### 3.1 배터리를 하나로 통합하는 것이 무게중심에 유리하다

| 구성 | 무거운 것의 위치 |
| :--- | :--- |
| 배터리 2개 | 몸통 + **마스트 위** ❌ |
| **배터리 1개** | **몸통 하부에 집중** ✅ |

**4족 보행은 절대 무게보다 무게중심 높이에 훨씬 민감하다**(측위 문서 6절). 배터리를 통합해
몸통 낮은 곳에 붙이고 선만 위로 올리면, 마스트에는 LiDAR 만 올라간다.

대가는 **고장 격리 상실**이다. 다만 10분 시연에서 카메라가 죽으면 어차피 시연이 성립하지 않으므로
실질 손해는 제한적이다.

### 3.2 포트 구성 — 3구가 꼭 필요하지는 않다

**GND 를 공유해야 하는 것은 LD06 과 C3 뿐이다.** XIAO 는 Wi-Fi 로만 통신하므로 누구와도
GND 를 공유할 필요가 없다.

```
보조배터리 ┬─ USB 분배 ┬→ LD06     (GND 공통 필요 ✅)
           │           └→ C3
           └───────────→ XIAO      (독립 무관)
```

**2구 + 분배 케이블(약 2,000원)로 충분하다.** 3구를 요구하면 자연히 대용량·중량 제품으로 몰린다.

> ⚠️ 보조배터리의 **USB-C 포트가 입출력 겸용**인 제품이 많고, 그 경우 다른 포트와 배타적이거나
> 출력이 되지 않는다. **가진 제품으로 세 부하를 동시에 켜보는 것**이 가장 빠른 확인이다.

## 4. 배선 실무 — 걸어다니는 로봇이라는 점

납땜보다 **이쪽이 실제 고장 원인이 된다.** 4족은 다리가 크게 움직이고, 선 하나가 걸리면 전도로 이어진다.

| 규칙 |
| :--- |
| 몸통 → 마스트 배선은 **한 다발로 묶어 한 경로**로 올린다 |
| **다리 관절 근처를 지나가지 않게** 몸통 중앙 상부로 우회한다 |
| 케이블 타이·스파이럴 튜브로 고정한다. **늘어진 구간을 만들지 않는다** |
| 커넥터에 장력이 걸리지 않게 여유를 두되 처지지 않게 한다 |

## 5. 도입 순서 — 변수를 하나씩 넣는다

LiDAR 를 사더라도 처음부터 무선화하지 않는다.

| 단계 | 하는 일 | 납땜 | 확인되는 것 |
| :---: | :--- | :---: | :--- |
| **1** | LD06 + 동봉 USB 어댑터 → **PC 직결**. rviz2 에 스캔 표시 | 0 | LiDAR 정상 여부 · 드라이버 동작 |
| **2** | 로봇에 얹고 **무게 측정** (선 연결한 채) | 0 | 부하 게이트 통과 여부 |
| **3** | 무선화 — C3 중계 + 전원 | 0 목표 | |

**1단계에서 LiDAR 와 드라이버가 정상임을 확인**한 뒤 넘어가면, 이후 실패의 원인이
배선인지 LiDAR 인지 즉시 격리된다. 그리고 **2단계에서 무게 판정이 나오므로,
초과로 나오면 3단계가 필요 없어진다.**

| ⑤ | **LD06 의 PWM/모터 제어 핀** 처리 방식 | X4 Pro 는 `M_CTR` 0V 에서 최고속. LD06 은 미확인 |
| ⑥ | **멀티미터 보유** | JST 극성 확인. LiPo 구성으로 되돌릴 경우 필수 |
| ⑦ | 인두·실납 보유 | LiPo 구성으로 되돌릴 경우 필수 |

### LiPo 구성으로 되돌릴 경우에만 필요한 절차

무게 초과로 보조배터리를 포기하면 **LiPo + MT3608 + TP4056** 구성이 되고 납땜이 약 12~15점 발생한다.
이때 **순서를 지키지 않으면 LiDAR 가 파손된다.**

```
① MT3608 에 배터리만 물린다        (LiDAR 미연결)
② 멀티미터로 출력을 재서 5V 로 맞춘다
③ 전원을 끊는다
④ 그 다음에 LiDAR 를 연결한다
```

MT3608 은 **가변저항으로 출력이 조절되는 모듈**이며 출하 상태가 5V 라는 보장이 없다.
②를 건너뛰고 바로 연결하는 것이 가장 흔한 사고다.
