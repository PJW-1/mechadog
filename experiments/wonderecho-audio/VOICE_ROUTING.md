# 음성 파이프라인 판정 구조 — 전부 규칙(결정론적)이다

이 문서는 `voice_pipeline.py` 음성 루프의 **판정 경로 전체**를 정리한다.
핵심 원칙은 하나다: **판정·명령·신원·답변 문장은 전부 코드가 정한다.** 규칙에
걸리지 않은 발화는 고정 문구 한 줄로 답한다. 자유 대화·자유 질의응답은 없다.

> **개정 (2026-09-23 · [ADR-38](../../docs/DECISIONS.md#adr-38))** — 음성 LLM(로컬 GGUF ·
> llama.cpp)과 그 fallback 경로, `machine_guard` 고지, 가상 MES 조회(`factory`), 로봇 상태
> 읽기(`status`, 구 WBS 4.7.10)를 폐기했다. 목표 스피커인 로봇 MP3 모듈은 미리 녹음한 문장만
> 재생하므로, 그때그때 만든 문장이나 실측 수치를 말할 수 없기 때문이다. 이 문서의 이전판에
> 있던 4~6절(factory · status · llm)과 8절(LLM 확장)은 지웠고, 7절(경계선)은 6절로 다시 썼다.
> 암구호 분기(4절)는 이전판에 없던 설명을 코드에 맞춰 더한 것이다.

```
마이크 → faster-whisper STT(한국어) → 정규화(공백·구두점 제거)
   │
   ▼  대화 게이팅(0절) — 대기/복귀, 웨이크워드, 후속 창
   ▼  route_query() — 아래 순서대로 처음 맞는 경로 하나만 탄다
   ┌──────────┬─────────────┬───────────┬──────────────────┐
   │ action   │ scenario    │ emergency │ unknown          │
   │ 로봇 명령 │ 고정 시나리오 │ 비상 접수  │ 규칙 없음         │
   │ 화이트   │ 34종         │ 로그+멘트  │ 고정 문구 한 줄   │
   └──────────┴─────────────┴───────────┴──────────────────┘
   │   (인증 대기 AUTH_WAIT 중에는 emergency 와 비상정지 말고는
   │    전부 암구호 대조로 간다 — 4절)
   ▼  결정론적 답변 문장 → Piper TTS → 스피커
```

```python
def route_query(query):          # voice_pipeline.py 요약
    if robotlink.match_action(norm) is not None:      return "action"
    if scenarios.match_trigger(norm) is not None:     return "scenario"
    if any(w in norm for w in EMERGENCY_WORDS):       return "emergency"
    return "unknown"
```

구체적인 규칙이 넓은 단어 검사보다 먼저다. "비상정지" 는 비상 전파가 아니라 정지
명령이고, "비상접수" 는 접수 시나리오다. 부분일치 단어 검사(emergency)가 먼저 오면
이 둘을 삼켜 버린다.

## 0. 대화 게이팅 (라우팅 전 단계, 전부 규칙)

| 구분 | 인식 구문 | 동작 |
|---|---|---|
| 웨이크워드 | `메카독` `메카도` `메카닭` `메카도기`로 시작해야 함 | 접두어를 떼고 나머지를 질의로 받는다. 없으면 무시 |
| 대기 전환 | `그만` `꺼져` `대기해` `잠자` | standby 모드 — 듣기만 하고 대답 안 함 |
| 복귀 | standby 중 `메카독 시작/깨워/일어나/켜져` | active 복귀 + 확인 멘트 |
| 후속 대화 | 답변 후 **20초**(`FOLLOW_S`) 안, 3자 이상 발화 | 웨이크워드 생략 허용 — "메카독 순찰 시작" 직후 "순찰 정지" 가 바로 이어짐 |
| 잡음 제외 | 3자 미만 / VAD 미감지 | 무시 |

- 정규화는 `[\s,.!?~…:'"·]` 제거뿐 — 띄어쓰기·말끝 흐림을 흡수한다.
- STT 도메인 바이어스(`STT_PROMPT`)로 "메카독/비상정지/순찰" 등 어휘를 whisper에 미리 알려 오청을 줄인다.
- 턴마다 먼저 하는 일: 로봇 상태를 읽어 인증 안내(4절)를 한 번 말하고, 단계 경고·시나리오
  큐를 비운다. **큐는 대기 모드에서도 재생한다** — 대기 중인 로봇에서도 경고는 나가야 하므로.
  3.5.6 단계 경고는 로봇 `/api/events` 의 `escalation_changed` 를 받아 `Hub.enqueue_say(urgent=True)`
  로 넣는다.

## 1. action — 음성 로봇 명령 (WBS 4.7.11, 화이트리스트)

`robotlink.match_action()` — 정규화된 발화가 **정확히 일치**하거나, 목록에 있는
명령 어미만 떼어내면 일치할 때만 실행한다. 부분 일치·유사어 없음.

| 발화(정규화) | 명령 | 발화(정규화) | 명령 |
|---|---|---|---|
| 비상정지·긴급정지·스톱 | `estop` | 순찰시작·순찰개시·순찰해 | `patrol_start` |
| 수동모드·수동제어 | `manual_on` | 순찰정지·순찰중지·순찰멈춰 | `patrol_stop` |
| 자동모드·수동해제 | `manual_off` | | |

- **명령 어미**: `해줘` `해주세요` `로전환해줘` `하세요` … 약 30종 + STT 오청
  어미(`해져` `해죠` `하죠` `했죠` `했어`)를 벗겨낸 뒤 일치를 본다.
  "비상정지해줘"는 명령이 되지만 `비상정지하지마`·`비상정지할까`는 목록에 없는
  꼬리라 **절대 명령이 안 된다** — 부정·의문이 명령으로 번역되는 것을 구조로 막는다.
- **의도적 제외**: `reset`(래치 해제)처럼 사람의 현장 확인이 필요한 명령은 음성
  경로에 없다. 로봇 런타임의 자체 안전 게이트(accepted 판정)도 그대로 탄다.
- 답변은 `robotlink.answer_query()` 가 돌려준 실행 결과 문장(확인 멘트 또는 거절 사유)이다.
- 한계: 표의 5종 명령뿐. "충전소로 가" 같은 새 명령은 코드 추가 없이는 불가.

## 2. scenario — 고정 대본 실행 (WBS 4.7.7)

`scenarios.TRIGGERS`의 구문이 발화에 **포함**되면 해당 시나리오 함수가 돈다.
대본·판정은 PC 코드, 모듈 재플래시 불필요.

| 카테고리 | 트리거 예 | 시나리오 |
|---|---|---|
| 신원·보안 | `경비모드` `신원확인` | `guard` — 성명 청취 → 명단 대조 → 확인/미등록 판정 (이름 발화는 출입 인증이 아니다 — 인증은 4절 암구호·사원증) |
| | `방문자확인` | `visitor_check` — 방문증 소지 여부 질의 → 규정 안내 |
| 안전 경고 | `안전모경고` `안전조끼경고` `보안경경고` `경고방송` | PPE 종류별 경고 방송 |
| | `제한구역` `전기위험` `화학물질` `금연` `촬영금지` | 구역별 경고 방송 |
| | `지게차경고` `하역경고` | 차량 작업 경고 |
| 화재·응급 | `화재대피` `대피방송` | `fire_evac` — 감지→대피→집결 3단 안내 |
| | `비상접수` | `emergency_response` — 위치 청취 → 접수 멘트 |
| 순찰·안내 | `순찰안내` `길막` `비켜` `순찰보고` `방문자안내` | 방송 / 목적지 청취 → `knowledge/` 검색 안내 |
| 일정·공지 | `교대안내` `식사안내` `점심안내` `점검안내` `출하안내` `안전수칙` `공지사항` | `knowledge/` 해당 문서 첫 문단을 읽어 안내 |
| 환경·기상 | `비온다` `우천` `춥다` `한파` `덥다` `폭염` | 기상 주의 방송 |
| 야간·훈련 | `야간순찰` `대피훈련` `훈련시작` | 안내 / 훈련 3단 방송 |
| 정보 | `안전점검` `분실물` `누구야` `뭐하고있` | 체크리스트·고정 멘트 |

- 다회전 대화도 코드로만: `guard`는 무응답 시 1회 재질의, `emergency_response`는
  위치를 다시 묻는다. 그 이상의 문맥 추적은 없다.
- 관제에서도 같은 테이블을 실행: `POST /scenario {"name":"fire_evac"}`.
- `knowledge/*.txt` 는 시나리오가 붙이는 **정적 본문**으로만 쓴다(2-gram 겹침 검색,
  WBS 4.7.6). LLM 프롬프트에 넣던 경량 RAG 는 폐기했다.
- 폐기: `상태보고` → `robot_briefing`(텔레메트리 브리핑)은 2026-09-23 지웠다.
- MP3 전환(4.7.21): `guard` 의 이름 되읽기와 `emergency_response` 의 위치 되읽기는 미리 녹음할 수
  없어 **고정 문장으로 바꿨다**(`identity_ok` 문구 · 「말씀하신 위치로 접수했습니다. 담당자가 출발합니다.」).
  이름과 위치는 기록(`ctx.event`)에만 남는다. 말하는 문장은 전부 `tf_tracks.tsv` 에 있어야 한다(README).

## 3. emergency — 비상 단어

`도와줘` `살려줘` `비상` `응급`이 발화에 포함되면: `emergency_log.txt`에 기록 →
"관제 센터에 전파했습니다" 고정 멘트. 전화·알림 같은 실제 외부 발신은 없고
기록+방송이 전부다. `비상정지`는 1순위 action이 먼저 잡고, `비상접수`는
scenario가 먼저 잡는다 — 순서가 의도된 것이다.

## 4. 인증 대기(`AUTH_WAIT`) — 암구호 분기 (WBS 3.8.2)

로봇 FSM 이 `AUTH_WAIT` 이고, 파이프라인이 active 이고, 등록 암구호가 하나라도 있을 때만
열린다(환경 변수 `MECHDOG_PASSPHRASES` 가 JSON 목록이 아니거나 비면 이 경로가 닫힌다).

1. 새 인증 대기마다 한 번 "인증되지 않은 사람이 확인되었습니다. 암구호를 말씀해 주십시오." 를
   말한다(`Hub.auth_prompt`). 이 안내 전에 시작된 녹음은 시도로 세지 않는다.
2. 방문객은 웨이크워드를 모르므로 웨이크워드 없이 받는다. 단 3자 미만 잡음은 시도로 세지 않는다.
3. `route_query()` 결과가 **emergency** 면 비상 경로(3절)가 먼저 처리한다. action 중에서는
   **`estop`(비상정지)만** 인증을 건너뛴다 — 미인증자가 "순찰 정지" 로 명령을 내리지 못하게.
4. 그 밖의 발화는 시나리오·명령·고정 문구로 보내지 않고 **원문**을 등록 암구호와 포함 대조
   (`match_passphrase`)한 뒤, 판정과 발화 시각만 로봇에 보낸다(`robotlink.post_auth_result`).
5. 통과하면 "암구호 확인됐습니다. 사원증을 카메라에 보여 주세요." → 사원증 대기. 로봇이
   `AUTH_WAIT` 를 벗어나면 `badge_verdict()` 로 성공(`PATROL` 등)일 때만 "인증되었습니다..." 를 말하고,
   `AUTH_FAILED`(L3) · `FAILSAFE` 면 말하지 않는다.

- 인증 대기 중에는 인식 원문을 콘솔·`/transcript` 에 남기지 않는다(판정만 기록).
- 말이 시작된 시각을 로봇에 즉시 알린다(`post_auth_pending`, ADR-37). ⚠️ 그 실측 근거는
  WonderEcho 녹음(최대 15초 + 무음 1초 + 전사) 기준이라, 입력이 XIAO 스트림(4.7.19)으로
  바뀌면 재측정이 필요하다.

## 5. unknown — 규칙 없음 → 고정 문구

위 어느 경로에도 걸리지 않은 발화는 `phrases.py` 의 `not_understood` 한 줄로 답한다.

> 「잘 못 들었습니다. 다시 말씀해 주세요.」

- 웨이크워드만 부르고 질의가 비었으면 `greeting` 문구로 인사한다.
- 두 경우 모두 후속 창(20초)을 연다.
- "메카독 배터리 어때", "A라인 생산량 알려줘" 같은 상태·운영 질문도 여기로 온다.
- 문구를 늘리면 MP3 트랙도 늘어나므로 한 문장으로 고정한다.

## 6. 경계선 — 무엇을 코드가 정하는가

| 항목 | 담당 | 이유 |
|---|---|---|
| 로봇 동작 명령 | action 화이트리스트만 | 자유 텍스트가 명령이 되는 경로 없음 (3.8.2 원칙) |
| 신원·암구호 판정 | 명단 대조 · 암구호 포함 대조 규칙 | 모델 판단으로 출입 허가하지 않음 (ADR-31) |
| 답변 문장 | 시나리오 대본 · 문구 라이브러리 · 고정 문구 | 미리 녹음 가능한 문장만 쓴다(MP3 전환, ADR-38) |
| 로봇 실측값 | 음성으로 읽지 않는다 | 구 4.7.10 폐기 — 대시보드가 보여 준다 |

## 7. 규칙을 늘리는 방법

- **지식 추가**: `knowledge/`에 `.txt`를 넣으면 재시작 시 자동 로드되어 시나리오의
  2-gram 검색에 바로 탄다. 실사 매뉴얼·SOP를 넣는 용도.
- **호출어·시나리오 구문**: `voice_data.rules.json` 을 고친다(8절). STT 오청 변형도 여기서 흡수한다.
- **새 명령**: 코드(`robotlink.ACTIONS` · `_ENDPOINTS`)에 추가해야 한다 — 화이트리스트는 코드가 정본이다.

## 8. 운영 데이터 — 코드 · 파일 · 규칙 JSON (음성 DB 폐기 · WBS 4.7.22)

| 저장 위치 | 내용 | 소비자 |
| --- | --- | --- |
| `voice_pipeline.py` 상수 | 후속 발화 시간·STT 힌트 (API 주소는 `--robot-api`) | voice_pipeline |
| 환경 변수 `MECHDOG_PASSPHRASES` | 암구호 JSON 목록; 없으면 공개 데모 문구 | voice_pipeline |
| `knowledge/직원명단.txt` | 신원 확인 명단 | scenarios.sc_guard |
| `phrases.py` | 응답 문구 (관리자 화면은 보기만) | phrases, 관리자 화면, 캐시 생성 |
| voice_data.rules.json | keywords·command_endings·action_commands·scenario_triggers (4섹션) | 발화 라우팅 |

음성 DB(`voice_data.db` · Supabase)는 2026-09-23 폐기했다. 목표 스피커는 TF 카드에 미리
녹음한 문장만 재생하므로 운영 중 문구·설정을 바꿀 이유가 없다.

JSON이 없으면 기존 코드 규칙을 사용한다. 파일이 바뀔 때만 검증/파싱한다.
명령·시나리오 동일 구문 충돌, 미등록 명령/시나리오/API를 거부한다.
비상정지 3개 보호 구문과 실제 실행 화이트리스트는 코드에 유지한다.
이전 규칙 파일에 남은 폐기 항목(`factory_rules` 섹션, `status`·`machine` 호출어 종류,
`robot_briefing` 시나리오 트리거)은 읽을 때 걸러 낸다(`voice_rules.drop_retired`) — 섹션 하나
때문에 파일 전체가 무효가 되어 사용자 규칙이 기본값으로 돌아가지 않게 하려는 것이다.

```powershell
python voice_rules.py --rules              # 지금 적용되는 규칙 보기
```

## 9. 운영 메모

- 기동: `start_voice.ps1` (기본 COM9 + 관제 API `:8090`). 가상 MES `:8095` 자동 기동은 없어졌다.
- 관제 API: `GET /status` `/scenarios` `/phrases` `/transcript` `/report`,
  `POST /scenario` `/mode` — 링크는 메인 루프 단독 소유,
  웹 요청은 큐 직렬화. 임의 문장 방송 `POST /say` 는 폐기했다(4.7.14 축소).
- 이력: `logs/voice-YYYY-MM-DD.jsonl` 일자별 저널 → `/report` 당일 요약.
  비상 발화는 `emergency_log.txt`에도 별도 적립.
- COM 링크는 임시 전송층이다. 로봇 4핀 I²C 로 음성을 중계하던 원안(4.7.9)은
  2026-09-23 실측으로 불가 판정했다(0x34 브리지는 명령 id 만 나른다). 목표는 듣기 =
  XIAO `:82/audio`(4.7.19), 말하기 = 로봇 MP3 모듈 `0x7B` 트랙 재생(4.7.20·4.7.21)이다.
  이 문서의 판정 구조는 전송층과 무관하게 그대로다.
- 기록: 2026-09-17 COM5 실기에서 "메카독 A라인 생산량 알려줘" 가 factory 경로로 결정론적
  답변을 냈다. 그 경로는 2026-09-23 폐기되어 지금은 고정 문구로 간다.
