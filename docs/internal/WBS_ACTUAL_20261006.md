## 실제 구현과 검증 경계

시연은 `nav.relaxed_follow` 동선 점 추종 + LiDAR 빈 방향 선택이다. 주 측위는 호스트 스캔 정합·전역 재측위이며 현행 지도는 `maps/home_20261006_remap2`다. ROS2는 스캔 관측·지도 작성에 사용한다. 기존 A*·AG/AH·ODOM/tf·MAP_POSE 시험 경로는 보존하지만 시연 주 경로의 완료 조건으로 삼지 않는다.

16:40~16:46 첫 완주와 17:41 리허설 완주가 보고됐다. 첫 완주 약 6분의 정합 점수 0.74~0.92는 물리 위치 정확도 비율이 아니다. 야간 21:11~21:26은 중간 정지·`finish_D` 이어가기를 포함한다. 완주 보고만으로 충돌·몸체 여유·비의도 비상정지의 종합 합격이나 600초 LINK_LOST 0 통과를 판정하지 않는다.

쓰러짐은 누운 박스 종횡비·정지 지속 규칙과 같은 프레임 VLM을 교차검증해 확정했다. 18:46:29 확정 뒤 18:47:30 웹 경보 확인·재개가 관찰됐다. 이후 추가한 L3 래치 대기, 정지점 사람 탐색, PPE 착용 재확인은 코드·설정 채택이며 실물 검증 대기다. C에서만 보호구 착용을 필수로 하고 A는 위험물, B는 쓰러짐 장면이다.

경고는 PC TTS 대신 로봇 MP3 모듈 TF 카드 트랙으로 낸다. 0185 청취와 PPE 촬영이 확인됐고 카드 0185~0199 추가가 보고됐다. SOUND ACK는 실제 청취 증거가 아니다(0192 ACK 뒤 무음 사례). 안내 트랙마다 실청취가 끝났다고 쓰지 않는다.

위험물 v1은 실물 라이터·보조배터리를 놓치고 PC·의자를 오검출했다. `hazard-synth-v2`는 로봇 배경 합성 학습 후보다. 미학습 실물 사진의 라이터 점수 0.87·0.88, 보조배터리 0/5는 오프라인 사진 평가이며 후보의 로봇 실시간 종단 합격이 아니다.

실물 우회 반복 0회, 장애물 제거 후 재개, 몸체 정지 지연, 중계→호스트→ROS2 지연, 독립 위치 정확도, L3 대기·사람 탐색·PPE 재확인, 합성 후보의 실시간 위험물 검증, 통합 병합본 실주행, RViz 캡처와 설치 flash 해시는 미확인이다. 위치 오정합·IMU 이상값·LINK_LOST도 미해결이다. LINK_LOST는 답변 요약 11회와 제공 30행 집계 12회의 범위가 달라 하나로 합치지 않는다.
