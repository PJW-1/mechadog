## 실행

저장소 루트에서 `python tools/field_plan.py --device mechdog-02 --out <결과폴더>`.
Python 3.11 이상, tkinter 및 저장소 의존성 PyYAML이 필요하다. 이 PC는 Python 3.12에서 시험했다.
GUI를 열거나 체크리스트를 내보내는 동작은 네트워크·로봇·OTA에 접근하지 않는다.
GUI 없이 출력하려면 같은 명령에 `--export`를 추가한다.

1. 기체 이름 옆 실제 `telemetry_device_id`를 확인한다.
2. 단계/검색으로 항목을 선택하고 절차·판정 기준·기존 참고 근거를 읽는다.
3. 설치 FW, 시험 Host 커밋, 측정자, 바닥·탑재·전압·카메라·PC·시험 시각을 입력한다.
4. 실제 측정한 숫자·반복 횟수·관찰·제외 사유를 적고 원본 JSON/CSV/영상/사진을 첨부한다.
5. 일부 측정/통과/실패/보류를 저장한다. 저장마다 새 폴더를 만들고 원본 사본과 SHA256을 보존한다.
6. 체크리스트 내보내기로 현재 기체의 진행표를 갱신한다. 저장은 UTC, 실제 시험 시각/과거 측정일은 조건에도 기록한다.

**19개 HW 묶음 + 기능 51/비기능 20 추적 항목**이다. 같은 실측을 90번 수행하라는 뜻이 아니다.
한 증거 파일을 관련 HW/TC 항목에 연결할 수 있지만 각 기준 충족 여부는 따로 판정한다.
팀장 기체의 시험, 코드 테스트, Git 병합은 현재 기체의 실측 통과로 승계되지 않는다.

## 항목별 측정 버튼 (사용자 정정 반영)

왼쪽에서 항목을 선택하면 그 항목에 연결된 실행 순서가 측정 버튼 아래 표시된다.
측정자·설치 버전·환경과 로봇 IP를 입력하고 **선택 항목 측정 시작**을 누른다.
구동/상태 변경 항목은 먼저 현장 준비 확인을 받는다. 별도 콘솔/수집기 번호 선택/결과 재가져오기가 필요 없다.
새 측정 창에서 진행 상황을 보고, 거리·각도·관찰을 입력한다. 완료/중단 결과는 해당 기체·항목에 자동 저장된다.
동시에 두 측정을 실행할 수 없다. 프로그램을 닫으면 진행 중 시험의 중단/ESTOP/저장을 기다린다.

**이동 테스트 일괄 실행** 버튼은 바닥 구동 단계(phase 2) 중 자동 경로가 있는 항목을
카탈로그 순서로 연속 실행한다: HW-011 두절 → TC-F-001 방향 → HW-007 자세 → HW-008 이동량
→ HW-009 선회 → TC-F-002 / TC-N-008 두절·래치. 한 번의 준비 확인으로 시작하며
항목마다 기존과 같은 세션을 열고, 각 항목이 끝나는 즉시 그 항목의 기록을 따로 저장한다.
한 항목이 오류로 중단되면 일괄 실행도 중단하고 완료된 항목의 기록은 남는다.
중단한 항목은 수집된 단계까지만 **일부 측정/보류**로 저장한다.
수동 계측 전용 항목(HW-010 진폭, HW-012 회피, TC-F-004/007/009/012 등)은 일괄 실행에
포함되지 않는다 — 자동 구동했다고 표시하지 않는 규칙과 같다.

| 항목 | 버튼이 실제로 수행하는 동작 |
|---|---|
| HW-001 신원 | 실제 ID에 해당하는 텔레메트리 3초 수집, 부팅 ID 기록 |
| HW-002 IMU | 정지30초 수집 → 축별 평균/편차/최소/최대, 원본 저장 |
| HW-003 전압 | 30초 수집 → 멀티미터 값 입력 → 전압 오차 계산 (방전/운용시간은 별도 시험) |
| HW-004 서비스 | SERVICE 진입/해제 송신·GPIO 사용자 조작 감지 → 새 플래그 기록 (WDT/OTA/거부 시험은 별도) |
| HW-006 통신 | 30초 수집 → 수신률/최대간격/seq누락/boot변경 기록 (장시간 부하/재연결은 별도) |
| HW-007 자세 | 준비 확인 후 0/-10/0/+10/0도 순서 명령·유지 → 외부 각도 입력·IMU 통계 |
| HW-008 이동량 | 전진3회→후진3회 구동, 매번 거리 입력 → mm/s 계산 |
| HW-009 선회 | 좌/우/후진 선회 각3회 구동 → 외부 각도·현길이 입력 → deg/s 계산 |
| TC-F-001 방향 | W/S/A/D 구동 → 각 실제 방향 확인 |
| HW-011 / TC-F-002 / TC-N-008 | 전진2초→HALT 없이 송신중단1.2초→ESTOP. 래치 관측/실제 정지 관찰 저장 |
| TC-F-003 / TC-N-011 | 각각 통신/전압 실행에 연결 |

명령 두절의 래치 **수신 시점**은 300ms 온보드 차단/물리 다리 정지의 정밀 측정값이 아니다.
50ms 물리 응답과 트롯 주기별 진폭은 외부 계측이 필요하므로 자동 통과를 만들지 않는다.
자세 시험은 시작 자세가 제대로 서 있는지 사람이 확인해야 한다. ACTION으로 자동 세우지 않는다.
자동 경로가 없는 항목은 **수동 계측 시작**으로 표시한다. 해당 항목 준비→외부 시험→실측값 비교를 안내하고 입력·증거를 자동 저장하며 자동 구동을 했다고 표시하지 않는다.
선행 구현 대기/정책상 제외 항목은 측정 버튼을 비활성화한다. 모든90항목의 자동 시험 구현이 끝났다는 의미는 아니다.

기존 field_measure 함수를 실행 엔진이 재사용하므로 CLI도 유지한다. 구형 1/7/10의 잘못된 자동판정은 복구하지 않았다.
GUI의 명령 두절 경로는 HALT를 보내는 drive_window를 사용하지 않고 별도로 송신을 중단한다.
기체 ID·IP·유효한 새 표본·수신 포트 소유권을 먼저 확인한다. 명령 송신기를 사용자가 종료해야 한다.
시험 후 자동 상태는 **일부 측정**이다. 위 표의 측정 범위와 전체 항목의 합격 기준이 다르므로 결과 검토 후 전체 통과를 판정한다.
기존 파일의 증거 가져오기 기능도 유지한다. 사진/CSV의 실제 기체 신원은 사용자가 확인한다.

## 기존 내 기체 자료

mechdog-02의 2026-09-11 폰 데이터: 179주기, pitch p95/max 1.84/2.67°, roll 2.62/4.19°, 2.77Hz.
기존 근거로 유지한다. 최장 연속 약8.5초와 WBS 10초 조건은 다르므로 임의로 완료 처리하지 않는다.
서비스 시험은 사용자가 이미 완료했다고 보고했다. 새 시험을 무조건 반복하기보다 당시 기체 ID·FW·증거·검증 범위를 먼저 대조한다.
설치/탑재/바닥이 달라져 영향을 받는 항목만 재측정한다. 프로그램은 프로필 수치나 WBS를 자동 수정하지 않는다.

실물 설치, 구동, GPIO, OTA, 실제 포트 연결, 각도/속도/지연 측정은 별도 실측 대기다.
