# 사례 7. TRACK 좌우 비대칭을 «데드밴드» 가정 대신 회전율 곡선으로 고친 사례

- 관련 결정: [ADR-40](../DECISIONS.md#adr-40)
- 측정 기록: [회전율 곡선](../measurements/2026-09-18-turn-rate-curve.md), [3.5.4 첫 실기](../../field_tests/results/20260918_3.5.4-track/summary.md), [3.5.4 재검증](../../field_tests/results/20260918_3.5.4-recheck/summary.md), [양방향 보정 실기](../../field_tests/results/20260919_bias-symmetry/summary.md)
- 코드와 설정: [`tracker.py`](../../host/behavior/tracker.py), [`actions.py`](../../host/behavior/actions.py), [`mechdog-01.yaml`](../../config/devices/mechdog-01.yaml)

모든 수치는 `mechdog-01` 한 대의 것입니다. 보정값은 기체별 서보 오프셋에서 나오므로 다른 기체에 옮겨 쓰지 않습니다.

## 초기 가설

2026-09-11~12 의 두 점 측정(`-3°` 효과 없음, `-9°` 거의 일자)으로 «우선회에 약 3.3° 데드밴드가 있다» 는 모델을 세웠습니다. 우선회 이득 0.228 °/s per deg, 직진 시 좌 드리프트 1.0 °/s 를 함께 썼습니다. 이 모델이 TRACK(사람 추종) 설계와 시험 상수의 근거였습니다([3.5.4 첫 실기](../../field_tests/results/20260918_3.5.4-track/summary.md)).

## 관측된 실패

2026-09-18 첫 TRACK 실기에서 좌우가 갈렸습니다.

| 방향 | 편차 추이(1초 평균) | 결과 |
| :--- | :--- | :--- |
| 왼쪽 | 183 → 11px | 약 12초에 데드존(40px) 진입 |
| 오른쪽 | 158 → 233 → 205px | 49초 동안 한 번도 진입하지 못함 |

그동안 조향 명령은 7~13.8° 로 계속 오른쪽을 가리켰습니다. Host 가 낸 명령 12건은 손 계산과 모두 일치해, 명령 계산이 아니라 기체가 따라오지 않은 문제였습니다.

첫 조치로 실측돼 있던 `straight_bias_deg`(−8.0)를 조향에 더했습니다. 재검증에서 오른쪽은 살아났지만(212 → 35px, 34초) 왼쪽이 −112.6px 에서 조향 0 으로 멈췄습니다. 데드밴드 모델로 계산하면 왼쪽이 꺾이려면 편차가 198px 을 넘어야 했습니다([3.5.4 재검증 1단계](../../field_tests/results/20260918_3.5.4-recheck/summary.md)).

## 근거 데이터

같은 날 IMU 요(yaw)로 각도별 순 회전율을 쟀습니다([회전율 곡선 2절](../measurements/2026-09-18-turn-rate-curve.md)).

| 조향 각도 | +28 | +20 | +12 | 0 | −12 | −20 | −28 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 순 회전(°/s) | +9.41 | +6.99 / +5.57 | +5.67 | +1.87 | −2.27 | −4.04 | −7.90 |

- **곡선은 0 을 연속으로 지납니다.** 평평한 구간이 없으므로 데드밴드는 없었습니다. 직접 잰 영점은 −5° 에서 −0.19 ± 0.66 °/s 였고, 이전 보정값 −8° 에서는 −1.40 ± 0.37 °/s(우)였습니다([곡선 4·5절](../measurements/2026-09-18-turn-rate-curve.md)).
- **조향 능력은 오히려 우측이 9~30% 강했습니다.** 드리프트(좌 +1.87 °/s)를 빼면 같은 |각도| 에서 우/좌 조향분 비가 1.09~1.30 입니다. 겉보기 «우회전이 약하다» 는 «로봇이 늘 왼쪽으로 휜다» 였습니다([곡선 3절](../measurements/2026-09-18-turn-rate-curve.md)).
- **같은 각도가 부팅마다 25% 달랐습니다.** `+20°` 가 부팅 B 에서 5.57, 부팅 C 에서 6.99 °/s 였습니다.

## 원인

두 점으로 세운 «데드밴드 3.3°» 가 틀렸습니다. `-3°` 가 효과 없던 이유는 데드밴드가 아니라 영점이 −5° 근처라 `-3°` 가 아직 좌회전 구간이었기 때문입니다. 오른쪽은 조향이 약한 것이 아니라 좌 드리프트를 먼저 갚느라 남는 회전이 적었고, 좌우 공통 보정은 좌회전 명령까지 깎아 왼쪽을 죽였습니다.

## 변경

1. **보정을 방향별로 바꿨습니다.** `straight_bias_deg` 는 드리프트를 거스르는 쪽(우선회)에만 더합니다([`tracker.py`](../../host/behavior/tracker.py)). 재검증 3단계에서 확인했습니다.
2. **보정값을 실측 영점으로 내렸습니다.** `straight_bias_deg` 를 −8.0 에서 −5.0 으로 바꾸고 `yaw_zero_angle_deg: -5.0` 을 기록했습니다([`mechdog-01.yaml:80,82`](../../config/devices/mechdog-01.yaml)). 이 값은 순찰 직진 보정([`actions.py`](../../host/behavior/actions.py))과 TRACK 이 함께 씁니다. 곡선 문서는 이 변경으로 TRACK 중간 구간의 좌우 비가 1.4 에서 2.0배로 벌어지는 대가를 받아들였다고 적었습니다(순찰 직진을 우선).
3. **양방향 보정은 실기로 기각하고 되돌렸습니다.** 곡선 대입으로는 양방향 보정이 더 대칭(110px 에서 1.02배)이라고 계산됐지만, 2026-09-19 실기에서 이득이 우 0.811 · 좌 0.163 으로 5.0배 벌어졌습니다. 명령 단계에서 이미 2.4:1 로 갈린 것을 곡선이 다시 벌린 것입니다([양방향 보정 실기](../../field_tests/results/20260919_bias-symmetry/summary.md)). 같은 기록의 판정 요약 표에는 «11.5배» 로 적혀 있어 본문 계산(5.0배)과 다릅니다. 이 사례는 본문의 이득 표를 따릅니다.
4. **다른 기체에는 복사하지 않습니다.** `mechdog-02` 는 편향이 반대쪽이라 `straight_bias_deg: null` 로 비워 둡니다([`mechdog-02.yaml`](../../config/devices/mechdog-02.yaml)).

## 동일 조건 재평가

같은 기체·같은 날·같은 런타임 절차(사람이 한 자리에 서 있고 관제 화면으로 순찰 시작)로 방향별 보정을 재검증했습니다([3.5.4 재검증 3단계](../../field_tests/results/20260918_3.5.4-recheck/summary.md)).

| | 시작 | 데드존 진입 | 걸린 시간 | 하강률 |
| :--- | ---: | ---: | ---: | ---: |
| 왼쪽 | −193.7px | −28.5px | 13초 | 16.1 px/s |
| 오른쪽 | +137.0px | +26.3px | 15초 | 11.2 px/s |

수렴 시간 비 1.15배로 기준(≤ 2.0)을 통과했습니다. 첫 실기에서 오른쪽은 49초 동안 수렴하지 못했습니다. 다만 이 재검증은 보정값 −8.0 일 때의 것이고, −5.0 으로 내린 뒤의 TRACK 좌우 수렴은 같은 절차로 다시 재지 않았습니다.

## 남은 한계

- 재검증은 px/s 로만 비교했습니다. 요약 로그에 IMU 요가 없어 °/s 로 좌우를 못 박지 못했습니다.
- 왼쪽 하강이 75~88px 에서 멈췄습니다. 좌 데드밴드를 따로 재지 않았고, 86px 은 우 데드밴드를 빌린 계산입니다. 곡선에서 데드밴드가 없다고 확인된 뒤에도 이 평탄 구간은 설명되지 않았습니다.
- 곡선(좌 0.280~0.334 · 우 0.269~0.343, 거의 대칭)과 추종 이득(0.163 대 0.811)이 같은 런에서 어긋났습니다. 배터리 전압 또는 지속 조향 대 100ms 마다 바뀌는 과도응답이 후보이며 확인하지 않았습니다.
- 부팅 간 25% 차이는 개루프 보정의 정확도 바닥입니다. 곡선 문서는 요를 보고 닫는 폐루프를 해법으로 적었습니다.
- 제자리 소각도 회전도 비대칭입니다(좌는 15° 이하에서 돌지 않고 우는 5° 에서 돎, [ADR-40](../DECISIONS.md#adr-40)).
