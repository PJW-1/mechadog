# 사례 연구

실기에서 드러난 문제를 어떻게 좁히고, 무엇을 재고, 어떻게 고쳤는지를 한 건씩 정리한 문서입니다. 각 문서는 **증상 → 가설과 배제 → 측정 → 원인 → 수정 → 검증 → 남은 한계** 순서를 따르고, 수치마다 원문(ADR, 측정 기록, 코드, 테스트)으로 링크를 겁니다.

5~10번은 실패에서 배운 것을 남기려고 **초기 가설 → 관측된 실패 → 근거 데이터 → 원인 → 변경 → 재평가(같은 조건 기록이 있을 때) → 남은 한계** 순서로 씁니다. 같은 조건으로 다시 잰 기록이 없으면 «같은 조건 재평가는 없습니다» 라고 적습니다.
