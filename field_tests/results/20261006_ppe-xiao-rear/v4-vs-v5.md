# ppe-v4 대 ppe-v5 — 같은 XIAO 원본 프레임 5841장

v5 는 v4 에 하단 각도 촬영 279프레임을 더해 미세조정한 모델이다(PR #385). PR #385 는 두 모델을 공개
test 와 하단 각도 사진으로만 비교했고, v4 는 XIAO 로 잰 기록이 없었다. 그래서 «로봇 시점 보강이 XIAO
에서도 나아졌나» 를 같은 조건으로 확인하지 못한 상태였다. 이 문서는 후면 재측정([analysis.md](analysis.md))
에서 남긴 원본 프레임에 두 모델을 같은 파이프라인으로 돌려 비교한다. 로봇·카메라는 쓰지 않은 오프라인
계산이다.

재현 명령(모델과 캐시는 저장소 밖에 둔다):

```bash
gh release download ppe-v4 --repo PJW-1/mechadog -p ppe.onnx -p ppe.json -D <저장소 밖>/models_v4
cp models/coco.onnx <저장소 밖>/models_v4/
R=field_tests/results/20261006_ppe-xiao-rear
python tools/ppe/ablation.py infer --frames $R/raw --models-dir models --cache <저장소 밖>/cache_v5.json --pads 0.08
python tools/ppe/ablation.py infer --frames $R/raw --models-dir <저장소 밖>/models_v4 --cache <저장소 밖>/cache_v4.json --pads 0.08
python tools/ppe/ablation.py compare $R/session.json --plan $R/plan.json \
    --cache v4=<저장소 밖>/cache_v4.json --cache v5=<저장소 밖>/cache_v5.json
```

두 모델을 동시에 돌려 각각 약 3분 50초 걸렸다.

## 파이프라인이 실기를 재현하는지

v5 를 오프라인으로 다시 돌린 결과가 실기 기록과 맞아야 v4 와의 비교를 믿을 수 있다.

- 구간 안 2866프레임 중 2824프레임(98.5%)에서 사람별 판정 목록이 실기 기록과 같았다.
- `standing-nohelmet` 은 판정 1285 · 일치 1257 · 불일치 2 · 확인불가 26 으로 실기 기록과 칸마다 같다.
- 13프레임(모두 `standing-none`, `02479`~`02545`)은 실기에서 사람이 0명이었는데 재추론에서는 1명이
  잡혔다. 그래서 `standing-none` 의 판정 수가 1561(기록)과 1574(재추론)로 다르다. 실기는 실행 장치
  선호 목록(`DmlExecutionProvider`, `CPUExecutionProvider`)만 기록해 어느 장치에서 돌았는지 알 수 없고,
  이 차이의 원인도 확인하지 못했다. v4 와 v5 는 같은 재추론 사람 박스를 쓰므로 두 모델 비교에는
  영향이 없다.
- 프레임 전체(구간 밖 포함)에서 실기 기록과 같은 판정을 낸 비율은 v5 92.8%, v4 90.1% 다. 구간 밖
  프레임은 구간 버튼을 누르지 않은 시간이라 정답이 없다. 이 값은 기록과의 일치율이며, 아래 «결과» 절의
  두 구간 합계 표에 나오는 실효 성공률(v4 도 92.8%)과는 다른 지표다.
- 같은 수치를 `ablation.py` 의 집계 코드를 쓰지 않고 판정 함수(`ppe_live_check.judge`)만으로 따로 다시
  세었다. v4·v5 의 구간별 판정·일치·불일치·확인불가·머리 클리핑 수와 사람 단위 맞대기 표가 모두 같았다.

## 읽을 때

- **같은 프레임에서 v5 가 v4 보다 판정을 더 많이 내렸고, 그만큼 맞혔다.** 머리 클리핑을 뺀 두 구간
  합계에서 확인불가가 187 → 113 으로 줄고 실효 성공률이 92.8% → 95.6% 로 올랐다. 방향은 PR #385 의
  하단 각도 사진 평가(착용자 58명 판정 불가 13 → 0)와 같다.
- **개선 폭은 작다.** 이번 프레임은 두 모델 모두 90% 를 넘는 쉬운 조건이었다. 10-06 낮 후면 맨머리
  오판(235건)은 v5 실기에서 나온 것이고, 그 프레임은 덧그린 이미지라 v4 로 다시 돌릴 수 없다.
- **대가가 있다.** v4 는 이번에 불일치가 0건이었고, v5 는 맨머리를 적합으로 읽은 판정이 2건 있었다.
  경보 단위로는 두 모델 모두 구간마다 같은 수(3·1회)를 확정했다.
- **오경보는 재지 못했다.** 두 구간 모두 기대가 위반이다. 착용자를 위반으로 읽는지(C1)는 이 비교로 알 수
  없다.
- 한 사람·한 장소·한 세션·후면 하나다. 16fps 연속 프레임이라 판정끼리 독립이 아니므로, 건수 차이에
  통계 검정을 붙이지 않는다.
