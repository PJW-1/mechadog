> 팀원이 매일 보는 진행 현황과 실제 담당 목록은 [ASSIGNMENTS.md](ASSIGNMENTS.md)이며 이 사전에서 자동 생성된다.

| 항목 | 값 |
| :--- | :--- |
| **팀 규모** | 3인 |
| **계획 기간** | 4주 (20 영업일) |
| **공수 단위** | M/D (인일, 1 M/D = 8시간) |
| **총 계획 공수** | **90.5 M/D** (기존 90.5 · 현장지원 +3.5 · 로컬 VLM 판독 +1.5 · 쓰러짐 규칙 +0.5 · 거리 유지 +1.0 — [ADR-35](DECISIONS.md#adr-35) · 온디바이스 웨이크워드 -1.5 — [ADR-31](DECISIONS.md#adr-31) · 배터리 지속시간 특성화 -0.5 — OI-4 · 현장지원 폐기 -3.5 · 음성 재편 -1.0 — [ADR-38](DECISIONS.md#adr-38)) |

작업 범위·선행·DoD·상태가 바뀔 때만 이 사전을 수정하고 `python tools/wbs_assignments.py`를 실행한다.
일상적인 코드 PR마다 WBS를 고칠 필요는 없다. 완료 상태는 팀장이 주간 리뷰나 마일스톤 종료 때 근거를 확인해 일괄 반영한다.
`R`은 A/B/C 작업 성격이며 실제 담당자는 [CONTRIBUTING.md 1절](../CONTRIBUTING.md)과 생성 목록을 따른다.

**이동거리 0 을 쟀다고 적게 된다**(목업으로 확인 — 기동 상태가 `FAILSAFE` 이고, 해제 + 10Hz 유지 뒤 `IDLE` 로 나온다). ⚠️ **③ 피치·롤 진폭은 이 도구로 못 낸다** — 펌웨어 텔레메트리 송신(`4.1.4`)과 IMU 드라이버(`OI-23`)가 선행이다. 자리를 만들어 두면 0 이 채워져 *"쟀다"* 로 보이므로 아예 거부한다. **[도구 준비 완료]** **네 모드로 재도록 확장했다 (2026-09-11)** — `--mode forward` `reverse` `turn_right` `turn_left`. ⚠️ **후진과 좌선회는 코드가 세운 가정을 확인하는 측정이다** — 회피 시퀀스는 `reverse_ms = reverse_distance_mm / forward_mm_per_sec` 으로 **전진 속도로 후진 시간을 계산하고**, 선회도 `turn_angle_deg`(+20, 우선회)를 그대로 써 **한 방향만** 쓴다. 즉 *"후진 = 전진"* 과 *"좌 = 우"* 를 가정하고 있으며, 4족 트롯에서 그것이 성립할 이유가 없고 개체 서보 오프셋도 비대칭이다(`[0, -36, -82, -14, -97, 3, 100, 36, 62]`). 어긋나면 **후진이 모자라 같은 장애물에 다시 붙거나 지나치게 물러난다.** 그래서 두 모드는 설정에 자동으로 적지 않고(`PROFILE_KEYS` 에 없다) **사람이 전진·우선회 값과 비교해 판단**하게 한다 — 차이가 크면 `reverse_mm_per_sec`·방향별 선회 키를 새로 만들어야 한다. 좌선회를 함께 재는 또 다른 이유는 `3.5.4` TRACK 락온이 x편차 비례로 **양쪽을 쓴다**는 것이다. ⚠️ **선회는 각도만으로 부족하다** — 제자리 회전 불가(ADR-11)라 원호로 **돌면서 앞으로도 가므로**(`Phase("turn", +60mm, ±20°)`) 시작·끝 **방향과 위치를 함께** 표시한다. 목업으로 네 모드의 명령 부호를 확인했다 **75%**), 좌선회 **6.8 도/s**(35.7/33.3/35.5도, 4%)에 **전진 84.3 mm/s 동반**, 후진 선회 **6.6 도/s**에 **후퇴 69.7 mm/s**(각도당 10.5mm). ⚠️ **가정 둘이 깨졌다** — ⓐ *"후진 = 전진"* 이 아니다(25% 느리다) → `reverse_mm_per_sec` 신설 ⓑ **회피 현·정면 성분·호 길이가 크게 달라지는데(93.5도에서 32%) 지금까지 표기가 없어 혼동이 있었다. 현으로 기록하면 각도와 함께 나머지로 변환된다. 검산 결과 **기록된 값은 전부 유효하다** — 회피가 쓰는 후진 선회 값은 30도 이하 구간에서 선형 근사가 잘 들어 오차가 0.01초다. 다만 여유 수치를 정정한다: 회피 순 여유 **+307mm**(R
