# 3.5.4 재검증 절차 — 보정 뒤 좌우 대칭

> **DoD 는 여기 적지 않는다.** 정본은 [`docs/WBS.md`](../docs/WBS.md) `3.5.4` 다.
> 직전 실기 기록은 [`TEST_MECHDOG/results/20260918_3.5.4-track/summary.md`](../TEST_MECHDOG/results/20260918_3.5.4-track/summary.md).

**왜 다시 하나** — #199 가 `gait_calibration.straight_bias_deg`(−8.0)를 락온 조향에 실었다.
보정 뒤의 좌우 대칭은 **실측 상수로 계산만 했고 실기로 확인하지 않았다.** 로봇을 켜고
오른쪽 대상을 쫓려 보면 바로 갈린다 — 줄자는 필요 없다.

---

## 1. 켜기 전 확인

| 확인 | 어디서 | 기대값 |
| :--- | :--- | :--- |
| 코드에 보정이 들어 있나 | `host/behavior/tracker.py` | `straight_bias_deg` 를 읽어 `angle` 에 더한 뒤 클램프 |
| 기체 보정값 | `config/devices/mechdog-01.yaml` | `gait_calibration.straight_bias_deg: -8.0` |
| 카메라 장착 방향 | `config/devices/mechdog-01.local.yaml` | `vision.mount_rotation: 180` |
| 주소 | 같은 파일 | 로봇 `.102` · 카메라 `.101` (**DHCP 가 바꾸면 이 파일만 고친다**) |
| 배터리 | 실물 | 만충에서 시작한다. 전압이 낮으면 드리프트가 달라져 **직전 측정과 비교가 안 된다** |
| 이전 로그 보존 | `logs/mechdog-01.jsonl` | 새 런이 **이어 붙는다.** 시작 전에 이름을 바꿔 둔다 |

```powershell
Rename-Item logs\mechdog-01.jsonl mechdog-01_20260918_track.jsonl
```

## 2. 실행

```powershell
python -m host.runtime --device mechdog-01 --dashboard-port 8000
```

기동 로그에 **`orientation_apply_failed`** 가 보이면 XIAO 가 `/orient` 없는 옛 펌웨어다 —
`firmware_xiao_vision` 을 재플래시하고 다시 시작한다(직전 런에서 그랬다). 화면이 뒤집혀
보이면 **판정이 뒤집힌 것**이므로 그대로 진행하지 않는다.

관제 화면은 http://127.0.0.1:8000/#dashboard 의 `제어 · 장치` 다.

## 3. 절차 — 왼쪽 60초, 오른쪽 60초

⚠️ **사람이 움직이지 않는다.** 직전 런은 대상이 계속 옮겨 다녀서 *"기체가 못 돈 것"* 과
*"대상이 도망간 것"* 을 데이터로 가르지 못했다. 이번에는 한 자리에 서 있는다.

1. 로봇 정면 **2~3m**, 화면 중앙에서 **왼쪽으로 치우친 지점**에 서서 가만히 있는다.
   `TRACK` 진입 후 **데드존 진입까지 또는 60초**.
2. 정지시키고 로봇을 원위치로 돌린다.
3. 같은 거리에서 **오른쪽으로 치우친 지점**. 동일하게 60초.

치우침은 첫 초의 `track_dev_px_avg` 가 **150~220px** 대가 되게 잡는다 — 직전 런
(좌 183 · 우 158)과 같은 눈금에서 비교하기 위해서다.

## 4. 판정

| 항목 | 기준 | 직전 런 |
| :--- | :--- | :--- |
| **오른쪽 수렴** | `track_dev_px_avg` 가 줄어 **40px(데드존) 안으로** 들어온다 | ❌ 49초간 실패 · 158 → 233px **발산** |
| **좌우 대칭** | 수렴 시간 비 **≤ 2.0** | 측정 불가(우측 미수렴) |
| 데드존 억제 | 데드존 안에서 `step`·`angle` 둘 다 0 | ✅ 유지 확인 |
| 명령 링크 | 초당 `sent = accepted = 10`, `last_cmd_age_ms` < 100 | ✅ 유지 확인 |

실측 상수로 계산한 예측은 **좌 3.96 / 우 4.62 °/s (1.17배)** 다. 여기서 크게 벗어나면
보정값 `-8.0` 자체를 다시 본다(그 값은 두 점 사이 보간이지 3회 측정이 아니다).

## 5. 중단 조건

- `batt_v` 가 **급격히 떨어지면** 중단하고 교체한다. 저전압 강제종료 임계는 아직 실측되지 않았다
  — 09-18 의 두 차례 종료는 모두 운용자가 끈 것이라 근거가 되지 못한다.
- 로봇이 사람 쪽으로 계속 붙으면 **E-Stop**. 안전 래치는 사람이 확인한 뒤 `RESET_SAFE` 로만 푼다.

## 6. 끝나고

`last_cmd_age_ms_avg`)이 거기 있고 판정 근거가 전부 그 파일에서 나온다.
원자료는 `TEST_MECHDOG/results/<날짜-시각>_3.5.4-recheck/` 에 둔다.
