# 4.7.3 눈 LED 상태 표시 시험 — 2026-09-18

에스컬레이션 5단계가 각각 지정된 색으로 표시되는지 확인한다.
요구사항은 FR-10.4, 색상표 정본은 config.yaml 의 escalation.led 다.

---

## 1. 시험 조건

1. 대상 WBS 4.7.3
2. 실물 기체로 진행했다
3. 로봇을 PC 와 C타입 케이블로 연결해 펌웨어를 올린 뒤 Wi-Fi 접속 상태에서 시험했다
4. 시험 스케치 firmware_mechdog_motion/diagnostics/led_probe/led_probe.ino
5. 원자료 led_probe.json
6. 확인 항목은 단계별 색상, 점멸 주기, 명령 적용 여부다

## 2. 결과

1. L0 순찰, blue, 상시점등, 적용됨
2. L1 관찰, yellow, 상시점등, 적용됨
3. L2 인증요구, orange, 상시점등, 적용됨
4. L3 경보, red, 2.0Hz 점멸, 적용됨
5. F 페일세이프, white, 상시점등, 적용됨
6. 5단계 모두 config.yaml 의 escalation.led 값과 일치한다
7. 눈으로 확인한 실제 발광도 순서대로 이상 없었다

## 3. 거부 확인

1. 색상표에 없는 magenta 를 보냈다
2. applied 가 false 로 돌아왔다
3. 모르는 색을 조용히 받아들이지 않는다는 것을 확인했다
4. 색상표를 코드가 아니라 설정에 둔 이유가 여기서 값을 한다

## 4. 미확인 항목

1. telemetry_count 가 모든 단계에서 0 이다
2. 명령 적용과 육안 발광은 확인했으나 텔레메트리로 되돌아온 확인은 받지 못했다
3. latched 가 모두 false 다. L3 유지와 관리자 확인 해제 경로는 이 시험 범위 밖이다

## 5. 판정

1. 색상 매핑과 점멸 주기가 규약대로 동작한다
2. 명령 적용과 육안 발광이 5단계 모두 일치한다
3. 미등록 색상 거부도 동작한다
4. 텔레메트리 반영과 L3 래치 동작은 별도 확인이 필요하다
