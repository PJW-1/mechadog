# 요구사항 대조와 연결 범위

이 문서는 웹 프로토타입의 화면/로컬 기능 범위입니다. 실행 방법과 현재 검증 범위는 [README](README.md)를 따릅니다. 실물 통합이나 팀 WBS 완료 보고가 아닙니다.

## 대조 기준

- 기능 확장 당시 팀 기준은 [PJW-1/mechadog dev b287eae4](https://github.com/PJW-1/mechadog/tree/b287eae4ca2b5751381e5ef4dfaf2d20b69886de)의 PRD·WBS·ARCHITECTURE·PROTOCOL과 blackbox/runtime 구현입니다. 이후 모든 원격 변경을 반영했다는 뜻은 아닙니다.
- 웹 기능명세 Draft v0.4 및 기존 웹의 제어권·검토·CSV·구역/장치 흐름을 확인했습니다. 원본 기획서나 이전 웹을 이 전달본의 실행 의존성으로 두지 않습니다.
- 2026-09-11 확정 범위는 DB/서버 연결에 앞서 웹 뼈대부터 갖추는 것입니다. 작업 페이지 전체 전환, 공통 로봇 3D, 수동 제어 옆 시점/위치, WASD/Space 입력을 반영했습니다.
- 카메라 확인에 사용한 팀 로컬 스냅샷은 `956b3b19`입니다. 해당 PROTOCOL의 POSE 정의와 별개로 motion firmware의 applyCommand에는 POSE 적용 분기가 없었습니다. 최신 원격의 현재 상태나 보유 장비 동작을 확정하는 근거는 아닙니다.

## 구현과 실제 연결의 경계

| 영역 | 웹에서 제공 | 실제 연결이 남은 항목 |
| --- | --- | --- |
| 관제/장치 | 예시 공장·기체 3D, 선택/회전/확대, 미수신 상태 | 실측 지도·장치 ID·센서 상태·측위·라이브 영상 |
| 순찰/수동 | 예시 임무 상태·제어권·WASD/버튼·STOP, 관측/계획/결과 화면 | 서버 임무·명령/ACK·제어권·구역별 경로/회피 |
| 사건 | 예시 필터·검토/메모, 저장 블랙박스 파일 읽기 | WS 사건 수신·인증/PPE 판정·서버 검토 저장 |
| 기록 | 웹 시연 이력·CSV, 선택 파일의 출처 표시 | 서버 감사·실제 운행 이력·증거 보관 |

## 데이터 의미

- FSM `state`와 대응 단계 `escalation`, 인증과 PPE 판단은 구분합니다. 수신되지 않은 값은 추정하지 않습니다.
- 블랙박스 필드는 `ts_ms`, `event`, `state`, `escalation`, `tracks[{track_id,box,score}]`, `detections[{label,score,box}]`, `telemetry`를 기준으로 읽습니다. `id/source/review`는 UI의 로컬 확장 필드입니다. 추적 ID는 영구 신원이 아니며 `ts_ms`를 촬영 시각으로 단정하지 않습니다.
- JSON 2MB/JPEG 15MB 한도·형식 검증·최대50개 파일 사건을 적용합니다. JSON과 이미지의 실제 대응 및 진본성은 자동 검증하지 않습니다. 파일은 브라우저 세션에서 읽습니다.
- 예시 검토와 정책 초안의 로컬 저장은 서버 감사/저장을 대체하지 않습니다. CSV는 수식 입력을 방어하고 출처를 표시합니다.

## 제어와 표시

- 키/포인터 해제, 초점 이탈, 페이지·대상 전환은 예시 STOP/제어권 해제로 처리하며 자동 재개하지 않습니다. Space 정지는 방향 입력보다 우선합니다.
- 수동 명령은 웹 상태/이력만 바꿉니다. 실제 로봇·3D 위치를 이동시키거나 장치 ACK를 생성하지 않습니다.
- 가상 시점·지도는 같은 선택 모델을 사용합니다. 실제 데이터 대기에서는 예시 관측을 숨기고, 그래픽 오류는 지속 안내와 다시 열기를 제공합니다.
- 웹은 PC 브라우저의 표시 계층입니다. Pi 5의 추론·센서·스레드·안전 판단이나 펌웨어 구조를 변경하지 않았습니다.
- `webmcp.js`는 지원 브라우저에서 상태 읽기·페이지 열기·관측 대상 선택만 제공합니다. 실제 기체 명령이나 파일 전송 도구는 없습니다.

실제 연결 단계에서는 그 시점의 팀 PRD·WBS·PROTOCOL과 구현을 다시 대조해야 합니다.
