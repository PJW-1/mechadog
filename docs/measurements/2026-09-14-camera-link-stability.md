# 카메라 무선 링크 장시간 안정성 — 2026-09-13~14

WBS 2.3.2(연속 스트리밍 2시간 중 브라운아웃·단절 0회)의 **부분** 근거 — 관측 시간이 DoD(2시간)에 미달하므로 완료로 표기하지 않는다.

## 조건과 직접 관측

- XIAO 카메라 → Wi-Fi → PC 런타임의 MJPEG 스트림을 관제·배지 실기·화각 측정과 병행해 장시간 유지했다. 전원은 보조배터리.
- 단일 세션 연속 관측: 약 **90분 이상 재연결 0건** — 21:04 기동 세션이 종료 시점까지 스트림 유지(이전에도 같은 날 선행 세션 운용, 당일 누적은 더 김). 그 사이 배지 실기·미등록 거절 검증·화각 측정을 전부 같은 링크로 수행했다.
- 관측된 스트림 품질: 약 **17fps** 지속, 프레임 손실률 ~0%(후반 큐 요약의 드롭은 최신 프레임 우선 큐 정책상의 폐기이며 링크 손실이 아니다), 워커 오류·stall·재연결 이벤트 0건.
- 별도 단시간 측정(2026-09-12, PR #74): 보조배터리 급전으로 29.6분 연속, 30초 간격 60회 관측에서 카메라·로봇 무응답 0회, RSSI −63~−57dBm·PSRAM 변동 0.

## 판정과 남은 검증

- 링크 자체는 시간당 단위로 안정적이나, **2시간 연속 무재연결 DoD는 미충족** — 남은 것은 연속 2시간 단일 관측뿐이다.
- 측정은 단일 기체·단일 AP·실내 환경이다. 브라운아웃은 무응답 관측으로만 추론했으며 전압 직접 계측은 아니다.
- 세션 종료는 링크 실패가 아니라 작업 종료(ESP 발열로 사용자 요청 정지)에 의한 것이다.
