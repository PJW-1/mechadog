# WBS 2.1.3 실측 — 초음파 표적 시험 (2026-09-15~16 · mechdog-01)

기준: **초음파·IMU·배터리 ADC·서보·액션그룹이 커스텀 스케치에서 읽기/구동 가능함을 확인**.
IMU·배터리 ADC 는 이미 확인됐고, 서보·액션그룹은 `4.1.2` 실기(#155)로 확인됐다. 남은 초음파를 표적으로 쟀다.

## 조건

- 로봇 `mechdog-01` · `192.168.1.101` · 본체 배터리(충전기 분리) · **안전 잠금 유지 — 움직이지 않았다**
- `python -m host.runtime --device mechdog-01 --no-vision --dashboard-port 8000`
- 센서 정면에 평평한 표적, 줄자는 센서 앞면 기준
- `sonar_probe.py` 가 `/api/telemetry` 에서 **새 seq 의 `dist_cm` 만** 5~6초 모았다(약 60개)

## 고치기 전 — 거리가 25.6cm 마다 되감겼다

| 표적 | 읽힌 값 (빈도) | 윗바이트를 되살리면 |
| :--- | :--- | :--- |
| 10cm | 11.2cm ×38 · **23.9 ×19** | 112mm — 정상 |
| 20cm | 20.2~20.6cm ×43 · **23.9 ×16** | 202~206mm — 정상 |
| 30cm | **4.0cm ×45 → 재측 3.4cm ×37** · 23.9 ×14~17 | 40+256 = **296mm**, 34+256 = **290mm** |
| 50cm | **21.1cm ×45** · 23.9 ×16 | 211+256 = **467mm** |
| 100cm | **0 ×25 · 23.9 ×21 · 25.2 ×9 · 25.5 ×4** | 1024 · 1007 · 1020 · 1023mm |

- **지금까지 찍힌 최대값이 정확히 25.5cm(255mm)** — 거리값의 **윗바이트가 늘 0**이었다.
- 모든 거리에 3분의 1꼴로 섞인 23.9cm 는 약 1m(1007mm) 반사가 같은 식으로 잘린 값이다.
- 30cm 앞 물체를 4cm 로, 1m 앞 벽을 24cm 로 읽었다. `safety.obstacle_stop_cm` 이 25 라 **이 값으로 `3.2.6` 을 만들면 헛돈다.**

### 원인

벤더 `UltrasoundSonar::getDistance` 는 레지스터를 쓰고 **STOP 으로 끝낸 뒤** 새로 읽는다. 우리 `sensor_hal.cpp`
`read_bytes` 는 **repeated START** 로 이어 읽었다. 초음파 모듈은 자체 MCU 가 있고, repeated START 뒤에는 첫 바이트만
주고 둘째를 0 으로 줬다. 같은 함수를 쓰는 IMU 는 정상이었다.

| 50cm | **45.8cm ×39 · 45.9 ×22** | 고치기 전 같은 자리의 복원값 46.7cm 와 일치 |

- **23.9cm 끼어듦 0**, 25.6cm 를 넘는 값이 정상으로 나온다.
- 기준보다 **0.8 / 1.4 / 4.2cm 짧게** 읽는다(약 5~8%). 줄자 기준점 차이를 포함한 값이다. 짧게 읽는 쪽은
  근거리 정지를 **일찍** 거는 방향이라 안전측이다. `3.2.6` 에서 임계 부근을 다시 본다.
