# 쓰러진 사람 재실측 계획 — 기존 YOLOX·VLM 그대로 — 2026-10-06

**모델을 바꾸지 않고 다시 잰다.** 쓰러짐 의심 진입에 쓰는 YOLOX-S(`models/coco.onnx`)와 확정에 쓰는
VLM(`Qwen2-VL-2B` bf16 · `person_down` 현행 문장)을 그대로 두고, 시연기에서 새로 찍은 사진으로
누운 사람 적중률과 오경보율을 잰다. 새 ONNX 는 만들지 않는다 — 시연 촬영이 이미 시작됐다(2026-10-06
사용자 결정).

## 왜 다시 재는가

[2026-09-28 카메라 벤치](../../field_tests/results/20260928_4.8.0-vlm-bench/summary.md)의 `person_down`·
YOLOX 결과(누운 사람 10장 중 VLM 7장 · YOLOX 1장)는 **폐기한다**(2026-10-06 사용자 결정). 그 벤치는:

- 누운 사람 10장(4장면) · 아닌 사진 15장뿐이었다. 사람 한 명, 한 곳, 한 시간대였다.
- YOLOX 는 측정 도구 없이 손으로 셌다. 임계값을 훑지 않았고, 놓친 9장이 문턱 근처였는지 아예
  안 보였는지 남지 않았다.
- 기체가 `mechdog-01` 이었다. 시연기는 `mechdog-02` 다(`config/devices/mechdog-02.yaml`).
- 질문 변형(P2·P4)을 같은 사진으로 고르고 같은 사진으로 채점했다.

ADR-42 의 근거 단락과 PRD 개정 이력의 «10장 중 1장» 은 새 결과가 나오면 바꾼다. 결정(확정은 VLM
«예» 2회)이 바뀌는지는 결과를 보고 따로 정한다.

## 무엇을 재는가

| 대상 | 운용 조건 | 도구 |
| :--- | :--- | :--- |
| YOLOX 누움 후보 | `vision.coco.conf_threshold` 0.5 이상인 사람 중 점수 최고 박스의 가로÷세로 ≥ `vision.fallen.aspect_ratio` 1.5. **한 장으로 의심(L1)에 든다** | `tools/probe/fallen_bench.py` |
| VLM `person_down` | 현행 문장 · 2초마다 순찰 판독, 구역 점검 판독. 어느 쪽이든 «예» 한 번으로도 의심(L1)에 든다. 의심 뒤 서로 다른 프레임의 «예» 2회로 확정(L3) — 사이에 «아니오» 가 끼어도 누적은 지워지지 않는다 | `tools/probe/vlm_bench.py measure` |

YOLOX 도구는 런타임과 같은 `Detector`·`PersonGate`·`FallenGate` 로 판정하고, conf 와 종횡비를
훑은 표를 함께 낸다. **훑기는 참고용이다** — 이 사진으로 기본값을 고르면 09-28 과 같은 «고른 사진으로
채점» 이 된다. 기본값을 바꾸려면 따로 정하고 다른 날·다른 사람의 사진으로 다시 잰다.

한 장씩 찍은 정지 사진이므로 `FallenGate` 의 정지 조건·`gap_ms`(박스가 잠깐 빠진 프레임도 후보로
잇는 것)·3초 확정은 재지 않는다. 걷는 로봇에서
찍은 프레임은 `4.8.5` 몫이다.

## 촬영 조건

- **기체**: `mechdog-02` 의 XIAO, 시연 때와 같은 장착. 바닥에서 렌즈까지 높이와 틸트를 재어 적는다.
  첫 장을 찍으면 사진을 열어 위아래가 맞는지 본다 — 촬영 도구는 `mechdog-02` 프로필의 장착 방향
  (`vision.mount_rotation`)을 카메라에 내린다. `mechdog-02` 프로필에는 이 값이 없어 전역 기본값 0 이
  내려가는데, 이 기체에서 잰 값이 아니다(`mechdog-01` 은 180).
- **로봇**: 시연 때처럼 서 있는 자세로 둔다. 도구는 로봇에 명령을 보내지 않는다 — 위치는 손으로 옮긴다.
- **런타임은 내린다.** 런타임이 스트림을 쥐고 있으면 캡처 도구가 함께 열지 못할 수 있다.
- **장소·조명**: 시연장 바닥과 시연 조명 그대로. 날짜·시각·장소·조명을 적는다.
- **사람**: 두 명 이상(A·B). 이름은 어디에도 적지 않는다. 옷 색이 다른 두 사람이면 좋다. 한 장면에는
  한 사람만 둔다 — 런타임은 점수 최고 한 사람의 박스만 본다.
- **거리**: 카메라에서 몸 중심까지 **150cm · 250cm** (필수), 공간이 되면 **350cm**. 몸 중심을 화면
  가운데쯤에 둔다.
- **장면마다 3장.** 한 장 찍을 때마다 로봇을 손으로 10cm 쯤 옮기거나 조금 돌린다. 자세는 그대로
  둔다. VLM 은 결정적이라 같은 사진에는 같은 답을 내므로, 서로 다른 프레임이어야 세는 의미가 있다.
- ⚠️ **사진은 저장소에 넣지 않는다** — 얼굴이 찍힌다. `<root>` 는 저장소 밖에 둔다
  (예: `~/mechdog-vlm-bench/<촬영일>_fallen`).

## 촬영 목록

장면 이름은 `<자세>_<사람>_<거리>` 다(예: `옆으로누움_A_150cm`). 사람이 없는 장면은 `<자세>_<거리>` 다.

**누운 사람 (`yes`)**

| 장면 | 자세 |
| :--- | :--- |
| `옆으로누움` | 몸이 카메라 시선과 직각, 옆으로 누움 |
| `하늘보고누움` | 직각, 바로 누움 |
| `엎드림` | 직각, 엎드려 누움 |
| `비스듬히누움` | 시선과 45° 쯤, 옆이나 바로 누움 |
| `머리쪽세로누움` | 머리가 카메라 쪽, 시선과 나란히 |
| `발쪽세로누움` | 발이 카메라 쪽, 시선과 나란히 |

**누운 사람 아님 (`no`) — 사람 있음**

| 장면 | 자세 | 왜 넣었나 |
| :--- | :--- | :--- |
| `서있기` | 정면으로 서 있기 | 기준 |
| `쪼그려앉기` | 쪼그려 앉기 | |
| `다리뻗고앉기` | 바닥에 앉아 다리를 앞으로 뻗기 | 09-28 VLM 의 유일한 오경보. 09-23 종횡비 1.06~1.43 (자세를 바꾸는 순간 1.89) |
| `양반다리` | 양반다리로 앉기 | |
| `무릎꿇기` | 무릎 꿇고 앉기 | |
| `허리굽히기` | 바닥의 물건을 줍듯 허리 굽히기 | 박스가 넓어진다 |

**누운 사람 아님 (`no`) — 사람 없음**

| 장면 | 놓을 것 |
| :--- | :--- |
| `옷안전모만` | 작업복·안전조끼·안전모를 바닥에 펼쳐 둔다 |
| `긴물체` | 사람 키만 한 물체(매트·긴 상자·자루)를 바닥에 눕혀 둔다 |
| `빈바닥` | 아무것도 두지 않는다 |

**필수 장수**: 누운 사람 6자세 × 2명 × 2거리 × 3장 = 72장, 사람 있는 `no` 6자세 × 2명 × 2거리 × 3장 =
72장, 사람 없는 `no` 3장면 × 2거리 × 3장 = 18장. 시간이 모자라면 사람 A 의 두 거리를 먼저 끝낸다.

## 찍는 법 (PowerShell · 저장소 루트에서)

`capture` 는 장면 하나마다 한 번 돈다. **Enter 를 칠 때마다 한 장**을 저장하고, `q` + Enter 로 다음
장면으로 넘어간다. 화면에 `Enter = 저장 → …\<장면>_NN.jpg` 로 지금 장면 이름이 나온다.

```powershell
$ip   = "<mechdog-02 XIAO IP>"
$root = "$HOME\mechdog-vlm-bench\<촬영일>_fallen"   # 저장소 밖
$who  = "A"                                           # 찍히는 사람 — 이름 말고 A·B
$yes  = "옆으로누움","하늘보고누움","엎드림","비스듬히누움","머리쪽세로누움","발쪽세로누움"
$no   = "서있기","쪼그려앉기","다리뻗고앉기","양반다리","무릎꿇기","허리굽히기"
foreach ($d in "150cm","250cm") {
  foreach ($p in $yes) { python tools/probe/vlm_bench.py capture --camera-ip $ip --device mechdog-02 --root $root --question person_down --label yes --scene "${p}_${who}_${d}" }
  foreach ($p in $no)  { python tools/probe/vlm_bench.py capture --camera-ip $ip --device mechdog-02 --root $root --question person_down --label no  --scene "${p}_${who}_${d}" }
}
```

사람 B 는 `$who = "B"` 로 바꿔 같은 반복을 돈다. 사람 없는 장면은 한 번만 찍는다.

```powershell
foreach ($d in "150cm","250cm") {
  foreach ($p in "옷안전모만","긴물체","빈바닥") { python tools/probe/vlm_bench.py capture --camera-ip $ip --device mechdog-02 --root $root --question person_down --label no --scene "${p}_${d}" }
}
```

잘못 찍은 장은 그 파일만 지우고 같은 장면을 다시 돌리면 다음 번호로 이어서 저장된다.

## 재는 법 (로봇·카메라 불필요)

```
python tools/probe/fallen_bench.py <root> --out <root>_yolox.json
~/.venv-mechdog-vlm/Scripts/python.exe tools/probe/vlm_bench.py measure <root> \
    --repeat 1 --out <root>_vlm.json
```

VLM 측정은 GPU 를 쓴다. 런타임이 VLM 을 올려 둔 동안에는 돌리지 않는다.
